# 301 · "种子对不上"排查：种子值三处一致，给出一份可对拍的真实群系表

> 用户口径（2026-09-25）：**「种子好像不对，放到种子查看器里面对不上」**。
> 结论：**种子值本身没问题**（三条独立通路一致），对不上要往"查看器的版本/对拍对象"上找。
> 为此新写了 `sandbox/read_biome.py`，把**存档里真实的生物群系**读出来当基准。

## 2. 生成参数全是原版默认（不是被 mod/datapack 改过）

```
server.properties : level-type=minecraft:normal   level-seed=(空)   generator-settings={}
overworld generator: type=minecraft:noise  settings=minecraft:overworld
                     biome_source = {type: minecraft:multi_noise, preset: minecraft:overworld}
出生点区块        : DataVersion=3700（= 1.20.4），Status=minecraft:full   ← 原生生成，不是搬来的
启用数据包        : vanilla / fabric / fabric-convention-tags-v1 / fabric-gametest-api-v1 / mmtr
```

`mmtr` 那个数据包**没有任何 worldgen 内容**（全库搜 `worldgen|dimension|biome` 无命中）、
`world\datapacks\` 也不存在 ⇒ **没有东西会改变地形**。

## 3. 新增：读真实群系来对拍（`sandbox/read_biome.py`）

1.18+ 的群系存在 section 的 `biomes` 里，**4×4×4 一格**，打包与方块调色板相同
（bits = `max(1, ceil(log2(len(palette))))`，每 long 低位起、不跨 long），
索引 `(y4 * 4 + z4) * 4 + x4`。multi_noise 群系是种子的**确定性函数**，
所以"存档里的群系"与"查看器里的群系"必须逐格一致 —— 这就是判据。

**存档实测（y=64）：**

| 坐标 | 真实群系 |
| --- | --- |
| **(80, 80)** 出生点 | `minecraft:beach` |
| (100, 100) | `minecraft:plains` |
| **(0, 0)** | `minecraft:cold_ocean` |
| (-104, -43)（侧线场） | `minecraft:cold_ocean` |
| (-40, 900)（样板站） | `minecraft:ocean` |
| (0, 1000) | `minecraft:ocean` |
| (500, 500) / (-500, 500) | `minecraft:plains` |

**512 半径网格（每 128 格）** —— 原点周围是一大片 **cold_ocean**，
西边 x≈-512 与东南 x≈512 是 **plains** 陆地，中间夹 `beach` / `river` / `deep_ocean`：

```
  x\z    -512   -384   -256   -128      0    128    256    384    512
 -512   plains plains plains plains plains plains plains plains plains
 -384   plains  ocean  ocean plains sunfl.  river  ocean  deep   plains
 -256   plains  deep   ocean plains  river  river  ocean  ocean  deep
 -128   plains  cold   cold  cold    cold   beach  river  ocean  ocean
    0   plains  cold   deep  cold    cold   cold   beach  ocean  beach
  128   plains  cold   cold  cold    cold   beach  river  beach  plains
  256   plains plains plains cold    beach  plains plains plains plains
```

（x=384 以北 / x=512 的部分还没生成，读不到。）

## 4. 所以"对不上"最可能是这三种

1. **查看器版本不是 1.20.4。** 大多数种子地图（如 Chunkbase）默认给的是**最新版**，
   而世界生成在 1.20.4 之后改过。**必须把版本选成 Java 1.20.4**，
   也别跟基岩版（Bedrock）的图对比 —— 两者群系/地形算法不同。
2. **拿"我们建过的地方"去比。** 侧线场、咽喉区、牵出线、样板站、雨棚……
   全是最近几天往海里填出来的石砖平台，**任何种子查看器都不会有**。
   已建范围大致是 `x=-144..-65 / z=-155..1020` 加样板站 `x=-52..-28 / z=800..1020`。
   要对比得挑**没动过的地方**（比如上面表里那些点）。
3. **数字录入**：它是**负数**的 64 位整数，前面那个减号别丢：`-5494863773433504150`。

**最快的判定**：在查看器里查 **(0, 0)** —— 应该是 `cold_ocean`；
查 **(80, 80)** —— 应该是 `beach`（那也是存档记录的出生点 `Spawn=80/63/80`）。
若这两格对得上，种子就是对的，剩下的差异是"我们建的"或"版本/缩放"。
