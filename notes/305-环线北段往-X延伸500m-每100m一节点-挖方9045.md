# 305 · 环线北段往 -X 延伸 500 m（每 100 m 一个节点）—— 挖方 9045 格

> 用户口径（2026-09-26）：**「轨道每100m一个节点，先往-x弄500M」**。
> 承接 notes/304（首段 +100 m 双线 + 平滑石头地基），本轮往 **-X** 再铺 500 m。

## 1. 勘察：先撞上"24 个区块没生成"

`z=1800` 一带不是全生成过的：**x=-512..-321 共 24 个区块（12 个 x-chunk × 2 个 z-chunk）缺失**。
`forceload add -528 1792 127 1823` 触发世界生成，等 20 s 后复查 **缺失 0**。
（这一步不能省：不生成就没法扫地形，也没法 fill。）

生成后的真实地形（走廊 `x=-500..100, z=1798..1808`，共 6611 列）：

| 项 | 值 |
| --- | --- |
| 地表最高 | **y=81** |
| 地表最低 | y=55 |
| ≥ y65（要挖） | **2519 列** |
| ≤ y62（要填） | 1760 列 |
| 最高点 >75 的 x | `-229..-27`，共 33 列 |

⇒ 这一段是**丘陵地**，与首段（岸线/水面）完全不同：**离 y=65 轨面高的地方要挖出 11 格宽的路堑**。

## 2. 施工（严格按 清障 → 地基 → 铺轨）

### 2.1 清障 / 挖方

```
fill <x0> 65 1797 <x1> 85 1809 minecraft:air replace      × 5 段（每段 100 m）
```

| 段 | x 范围 | 换掉的方块 |
| --- | --- | --- |
| 1 | -500..-401 | 308 |
| 2 | -400..-301 | 451 |
| 3 | -300..-201 | **2734**（第一次被 RCON 掉线打断，重试成功） |
| 4 | -200..-101 | 3045 |
| 5 | -100..-1 | 2507 |
| | **合计** | **9045** |

⚠ **挖方只做到 `x=-1`**，**故意不碰 `x=0`** —— 那里有首段留下的两个节点方块
（notes/304 刚被这个坑咬过：`y=65` 的 `air replace` 会删掉节点）。

第 3 段那次失败是**已知的 RCON 瞬时掉线**（`connection closed by server while reading`，
`sandbox/rcon.py` 自带 4 次重试仍失败），**重跑一次即成功** —— 别当成 fill 本身有问题。

### 2.2 地基（平滑石头）

```
fill -500 62 1798 0 64 1808 minecraft:smooth_stone
```

**换了 16500 格**（= 501 × 3 × 11 = 16533，其中 x=0 那一列 33 格本来就是平滑石头，未计入）。
断面与首段完全一致：`y=62..64`、`z=1798..1808`（11 宽）。

### 2.3 铺轨：**每 100 m 一个节点**

`sandbox/build_ring_north_west.txt`，10 条 `rail add`（2 条轨 × 5 段）：

```
rail add    0 65 1800  -100 65 1800 --speed=160
rail add -100 65 1800  -200 65 1800 --speed=160
rail add -200 65 1800  -300 65 1800 --speed=160
rail add -300 65 1800  -400 65 1800 --speed=160
rail add -400 65 1800  -500 65 1800 --speed=160
（z=1806 同样 5 条）
```

**相邻两段共用中间那个节点**（`x=-100` 被第 1、2 段各写一次）——
朝向相同 ⇒ 同一状态，这是刻意的：**每 100 m 一个节点正是为了以后能按段接曲线/道岔**。
连通性可从 hex 对拍确认：第 1 段 hex 以 `…FFFFFF9C…`（=-100 的补码）结尾，
第 2 段 hex 以它开头 ⇒ 两段共用 `x=-100` 这个端点。

## 4. 现在这条北段的全貌

```
                 x=-500 …… -100      0      +100
  z=1800  ────────●────●────●────●────●──────●        轨（每 100 m 一节点）
  z=1806  ────────●────●────●────●────●──────●
  地基    smooth_stone y=62..64, z=1798..1808, x=-500..100（全长 600 m）
  限速    160 km/h，普通轨，双线轴线间距 6 格
```

- **总长**：`x=-500 .. +100` = **600 m**（双线 ×2 = 1200 m 轨）
- **节点**：每 100 m 一个，共 `x = -500,-400,-300,-200,-100,0,100` 七处 × 2 轨 = 14 个
  （其中 `x=100` 那对是首段东端）

## 5. 回滚

- **拆某一段**：杀掉该段两端的节点方块即走 `BlockNode.onBreak2` → `PacketDeleteData`。
- **重铺**：`sandbox/build_ring_north_west.txt` 整文件重推即可（同端点=同 hex，原地替换，实测幂等）。
- **填方不回滚**（挖掉的 9045 格是自然地形，无法还原）。
