# 267 — 制动 P3+P4：电空混合（Blending）与黏着截断/WSP

用户口径（2026-09-25）：**「继续下一步吧」** —— 按设计文 `docs/01-设计/制动系统-气压与制动力模型-设计.md`
的分片顺序做 **P3（电空混合）** 与 **P4（黏着截断 + WSP）**。两片都落在"力的合成"这一层，一起做完只需要一次换 jar。

## 1. P3 电空混合（规格模块三）

```
管压那份 = 司机诉求 B_demand（含 AFB 补气诉求里大的那个）
B_ed_actual   = min(B_demand, B_ed(v))                 ← 电制动先吃饱
B_mech_target = B_demand − B_ed_actual                 ← 机械只补缺口
P_bc_target   = 反解（含缸簧与闸片衰减 κ(v)）
P_bc_final    = min(P_bc_target, 分配阀给的缸压)        ← **EP 阀只削不加**
总电制动      = max(司机电阻制动手柄, 混合电制动)        ← 电机只有一台，取大不相加
```

实测（`MmtrPneumaticBrakeTests`，dt=50 ms，BR101 单车）：

| 场景 | 结果 |
| --- | --- |
| 200 km/h、8 档 | 诉求 78.6 kN（= 102.2 × κ(200)）**全被电制动吃掉** ⇒ 缸压被 EP 阀削到 **0** |
| 静止、8 档 | 电制动已淡出为 0 ⇒ 缸压 **3.80 bar**、机械担满 102.2 kN（"只削不加"的反面） |
| 100 km/h、电制动手柄推满 + 8 档 | 总电制动 **150 kN**（= max(手柄 150, 混合 132.7)），**不是相加的 282 kN** |
| `blendingEnabled=false` | 缸压 = 分配阀那档、自动电制动不参与（= P1+P2 行为，逐位可回退） |

**总力不变、分配随速度变** —— 这就是混合的全部意义：闸瓦少磨、电机多出力，制动距离不变。

## 2. P4 黏着截断与 WSP（规格模块四）

```
μ_brake(v) = min( 7.5/(v_kmh + 44) + 0.161 , 轨面/撒砂给出的 usableMuMax )
B_actual   = min( B_气 + B_电 , μ_brake(v)·m·g )
```
- `wspEnabled=true`（默认）：超限即钳到上限（真车点刹保持峰值微滑）；
- `wspEnabled=false`：断崖到动摩擦 `wheelSlipMu·m·g`（默认 0.12）—— 力**反而更小**，并打一条自白日志
  `[MMTR-BRK] 黏着拉穿且无 WSP：…`（节流 2 s）。

**实测结论（重要，写下来免得以后误判）**：在新标定下**干轨与湿轨永远吃不穿**，P4 实际是一条**天气特性**。

| 场景（BR101 单车 84 t） | 需求 | C-K 上限 | 结果 |
| --- | --- | --- | --- |
| 8 档全常用 @0 / 200 km/h 干轨 | 102 / 79 kN | 273 / 158 kN | 不截 |
| EB @0 / 200 km/h 干轨 | 138 kN | 273 / 158 kN | 不截 |
| EB 湿轨（μ=0.20） | 138 kN | 165 kN | 不截 |
| EB **落叶/油污**（μ=0.07） | 138 kN | **57.7 kN** | **截断**（8 档同理：78.6 → 57.7） |

原因很直白：C-K 上限对应 **0.19g（200 km/h）～0.33g（静止）** 的减速度，而 UIC 锚给的常用制动只有
**1.04 m/s² = 0.11g** —— 离黏着极限还有一大截。要让"干轨拉满就打滑"成立，得先把制动重量调大
（或改标定口径），不是改 P4。

顺手修掉一处**自己埋的坑**：早前用 here-string 往运行时配置里插气压键时，插入块的换行是 LF 而文件是 CRLF，
末行还与下一行粘在一起（`"padMuFloor": 0.28,      "adhesionMuMax": …`）——JSON 仍然合法所以没被发现。
这轮把 5 份配置**行尾统一成 CRLF** 并逐份 `ConvertFrom-Json` 校验过（教训：脚本改配置必须回读校验）。

  WSP 钳位 vs 断崖、控制器端到端（落叶 200 km/h 8 档 ⇒ 减速度按截断后的 57.7 kN 算）；

## 5. 实机可见的变化

- **HUD 的"缸压"不再等于设计表里那个数**（那是*诉求*）：只要电制动能帮忙，缸压就会被削低甚至到 0。
  blending 关掉时才与设计表一致 —— 这条要记住，否则会以为"缸压没建起来 = 坏了"。
- HUD 的"制动力"行现在会显示 `xx kN（气 y · 电 z）`，混合开启后**电的那份明显变大**（这正是应该看到的）；
  被黏着截断时追加 `· 黏着截断` 并转警示色。
- 制动距离**不变**（总力还是司机诉求）；闸瓦负担变小、再生/电阻制动承担更多。
