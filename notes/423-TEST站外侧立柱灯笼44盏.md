# 423 · TEST 站外侧立柱吊灯笼（44 盏）

> 用户口径（2026-10-13）：**「再往车站加点装饰吧，加点灯笼放在站台外侧的立柱左右」**。
> 做法直接沿用 notes/300 的老口径（每根柱子 `z±1` 各一盏、`y=69` 吊在屋面正下方）。

## 1. 勘察（直读存档）

TEST 站（station `185C4926B07BE21A`，z=800…1020）一共 4 条柱列，但两侧性质不一样：

| 柱列 x | y=69 上是什么 | 说明 |
| --- | --- | --- |
| **−52**（西外侧） | **11 根** `stone_bricks` 柱（z=810/830/…/1010） | y=70 是 `stone_bricks` 屋面 ⇒ 可吊 |
| **−28**（东外侧） | **11 根** `stone_bricks` 柱（同上 z） | y=70 是 `stone_bricks` 屋面 ⇒ 可吊 |
| −45（西内侧） | 4 块 `mtr:stop_marker`（818/836/981/999）＋空气 | 本站这里是 **APG 玻璃墙**（y=66/67），不是石砖柱 |
| −35（东内侧） | 同上（镜像） | 同上 |

所以"站台外侧的立柱左右" = **x=−52 与 x=−28 两列**，每列 11 根柱 × 两侧 = **22 盏**，两列共 **44 盏**。
内侧两列没做（不是石砖柱，而且 y=69 那一层已经给了停车对标牌子）。

## 2. 挂法（与 notes/300 完全一致）

```
y=70  stone_bricks 屋面（起拱列）
y=69  minecraft:lantern[hanging=true,waterlogged=false]   ← 灯在柱子 z±1
y=68  空气
…
y=66  立柱顶（柱子本体在 z 处，灯在 z±1，不打架）
```

西列 22 盏的 z：809/811、829/831、849/851、869/871、889/891、909/911、929/931、949/951、969/971、989/991、1009/1011（东列同）。
间距沿站台**每 10 格两盏**（柱子每 20 格一根），与停车牌子（818/836/981/999）**不撞格**。

## 3. 工具（预检 → 下发 → 读回）

`sandbox/tmp/add_lanterns.py`（一次性的铺场脚本，纪律照 notes/300 §3 与停车牌子那一套）：

* **先读档预检**：目标格必须是空气（不许顶掉已有的东西）、`y+1` 必须有实心方块托着 —— 缺一条就不发；
* 下发只发 `setblock`；`Could not set the block` 是**幂等空操作**（notes/300 §4），不算失败；
* 下发前后各 `save-all flush`，**读回存档**逐盏核对；
* `--clear --apply` 可全清回滚。

## 4. 验收（直读存档，44 盏逐一核对）

| 判据 | 结果 |
| --- | --- |
| 预检 | 可下发 **44**／被占位 **0**／上方没屋面 **0** |
| 下发 | `44 条：成功或空操作 44｜失败 0` |
| 读回 | **44/44** 都是 `minecraft:lantern[hanging=true,waterlogged=false]` |
| 立柱没被动 | `(-52,69,810)=stone_bricks`、`(-28,69,810)=stone_bricks` |
| 算术自检 | y=69 这一层非空气 = **74** 格 = 44 灯 + 22 柱 + 8 停车牌 ✓ |
| 停车牌子 | 登记表仍是 **8 条**（灯笼与牌子不同格，互不影响） |

## 5. 两个读档坑（值得记住）

1. **1.20.4 的段落调色板在 `sections[].block_states.palette`**（不是顶层 `Palette`），数据在 `block_states.data`；
2. **`sections[].Y` 读出来是 `Byte(4)` 这种包装对象** —— 不 `int()` 就一个都命中不了；
   另外 **`minecraft:air` 也可能是非 0 的调色板项**，判空气要按**状态串**判，不能按"索引 != 0"判。
   （这三条一开始让我扫出"0 格非空气"，白折腾一轮。）

## 6. 回滚

```
python sandbox/tmp/add_lanterns.py --clear --apply     # 44 盏清成空气（会读回核对 44/44 是空气）
```
