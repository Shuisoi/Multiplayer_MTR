## 1. ★ 先修一个潜伏的 bug：`_FACING_ROTATE` 写成了旋转，其实是镜像

`axis="x"`（东西向站）靠「输出时把 x 与 z 对调」复用南北向站的几何。
朝向也要跟着换，我原来写的是：

```python
_FACING_ROTATE = {"east": "south", "south": "west", "west": "north", "north": "east"}   # ✗ 旋转
```

**这是错的。** 坐标映射是 `(x_w, z_w) = (z_l, x_l)`，方向向量 `(dx, dz) → (dz, dx)`
—— 那是**关于 x=z 的镜像，不是旋转**：

| 局部方向 | 向量 | 映射后 | 世界方向 |
| --- | --- | --- | --- |
| east | (1, 0) | (0, 1) | **south** |
| **south** | (0, 1) | (1, 0) | **east** |
| west | (-1, 0) | (0, -1) | **north** |
| **north** | (0, -1) | (-1, 0) | **west** |

⇒ 正确的是 **east↔south、west↔north 两两互换**：

```python
_FACING_ROTATE = {"east": "south", "south": "east", "west": "north", "north": "west"}   # ✓ 镜像
```

**为什么一直没暴露**：站台方块只用 `east`/`west` 两种朝向，而这两个在错版本里**恰好是对的**
（east→south、west→north）。只有用到**沿轨方向**（`south`/`north`）的方块才会咬人 ——
**信号灯正是**。已修正，并在代码里写了注释说明"这是镜像不是旋转"。
修正后站台方块产物**逐字未变**（east/west 两项没动）。

## 2. 新增：`signal_commands()` —— 站台两端 8 盏，固定做法

```python
SIGNAL_POLE   = "mtr:signal_pole"
SIGNAL_LAMP   = "mtr:signal_light_4_aspect_1[facing={facing},is_22_5=false,is_45=false,power=0]"
SIGNAL_POLE_Y = 66
SIGNAL_LAMP_Y = 67
```

规则（写死，不再每次手推）：

| 项 | 值 |
| --- | --- |
| 位置 | **站台边缘列**（横断面 `plat_w_edge` / `plat_e_edge` = `C∓5`） |
| 沿轨四位 | `z_from`、`z_from+1`（进站端）与 `z_to-1`、`z_to`（出站端） |
| 朝向 | **低坐标那盏朝 +along、高坐标那盏朝 −along** |
| 数量 | 2 列 × 4 位 = **8 盏**（每盏 = 1 条柱 + 1 条灯头 = 16 条 `setblock`） |
| 输出 | 独立文件 `<prefix>_signals.txt`（`axis=x` 时同样经 `_swap_command` 转置） |
| 开关 | `--no-signals` |

## 4. 顺带把 `stamp_station.py` 也接上（并修掉它的一处手抄）

`stamp_station.py`（一条命令盖站）原来**自己手抄了一遍 rail 命令**，那份不会跟着 `axis` 转置走
⇒ 用 `--axis x` 会铺出方向错误的轨。本次改成**复用 `rail_commands(st)` + `_swap_command`**。

改动：

1. `--axis {z,x}`、`--no-signals` 两个新参数
2. `push_rails()` 改为复用生成器（不再手抄）
3. 新增 `push_signals()`：落 `<prefix>_signals.txt` + **自动跑 `world scan-signals`**
4. 步骤从五步变六步打印（④ 铺轨 → ⑤ 落灯+扫描 → ⑥ 清 forceload）

## 5. 施工步骤现在是**五步**（写进 `gen_station.py` 的 docstring）

```
1. forceload add …              （含 fill 整段 + 轨两端）
2. rcon_batch --file <prefix>_fills.txt
3. push_rail_commands.py <prefix>_rails.txt      ← 必须先 fills 后 rails（清障会删节点）
4. rcon_batch --file <prefix>_signals.txt  →  world scan-signals
5. forceload remove all
```

`stamp_station.py` 一条命令全包上面五步。

**关键次序**：fills 的清障 `fill … 65 … air replace` 会删掉站台范围内的节点方块，
靠第 3 步重铺复原 —— 这不是 bug，是流程（notes/304/306）。
第 4 步之后必须**扫一次**，否则是"有灯方块、无引擎登记"（铁律 6）。
