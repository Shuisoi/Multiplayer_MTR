# 383 — 常驻固定音 354.5 Hz：一次**读错**的纠正，和由此加的一层

> 起因：上一轮我根据新参考录音（`【4K前面展望】…京急線 横浜→品川 … 120km_h`）
> 说"实录最突出的线是 708.6 Hz，而我们模型的载波是 400 Hz —— 载波定错了"。
> **这个判断是错的。**动手之前按惯例先复核，一复核就翻了。

## 1. 复核：709 Hz 到底动不动

用 692~728 Hz 这一个窄窗、每 0.5 s 跟踪一趟（16~59.5 s，共 88 个测点）：

| 时刻 s | 16 | 18 | 20 | 22 | 24 | 26 | 28 | 30 | 32 | 34 | 36 | 38 | 40 | 42 | 44 | 48 | 52 | 56 | 58 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 频率 Hz | 722 | 691 | 718 | 717 | 708 | 721 | 703 | 716 | 708 | 708 | 708 | 709 | 709 | 708 | 706 | 709 | 708 | 707 | 711 |

**24 s 之后基本就是 703~717 Hz（±1%）**，而同一时间牵引的谐波扇形正以 **+27.5 Hz/s** 往上扫
（量法：60~400 Hz 里最低那条明线，21.0 s 的 100 Hz → 25.25 s 的 217 Hz）。

> **扇形在扫、它不动 ⇒ 它是固定频率，不是速度锁定。**
> 所以它不是载波，是**辅助机械**（压缩机 / SIV / 冷却风机），跟大西那条 322 Hz、老参考里的 2097 Hz 同类。

**结论：载波表（175→400 Hz）这次不动。**上一轮那个"载波定错了"作废。

## 2. 顺便把 709 的族关系量清楚

8 s 平均谱（32~42 s 平稳段）里，各固定音**相对该段总 RMS** 的电平：

| 段 | RMS | **354.5 Hz** | **709 Hz** | 1063.5 | 1418 | 520 |
|---|---|---|---|---|---|---|
| 32~42 s 平稳 | −13.6 | **−21.7** | **−26.4** | −47.7 | −47.1 | −39.3 |
| 16~26 s 加速 | −17.8 | −36.7 | −39.6 | −53.2 | −52.6 | −42.9 |
| 46~56 s | −13.3 | −31.0 | −44.2 | −44.4 | −36.5 | −45.9 |

- **354.5 = 709 / 2** ⇒ 基音 + 2 次，差 4.7 dB。3 次以上很弱 ⇒ `count: 2`。
- 它的**频率全程不动，电平却随区段起伏十几个 dB** —— 辅助机械在通断。
  这里先按平稳段的最强值（−21.7）定成**常驻**，起伏那件事等有了更多段落的统计再定。

## 3. 实现

`SPEC_KEIKYU_2100_GTO.fixedTones` 加一条：

```js
{ hz: 354.5, amp: 0.017, count: 2, decay: 0.74 }   // 常驻；2097 那条仍是间歇 7/14
```

- 它走**已有的固定音通路**（`fixedTonePartials` → preview 里单独合成、不变调、加在壳子之前），
  所以**不需要新代码**，只是给 spec 加数据。
- `selftest.mjs` 里那条"京急固定音只剩 2097、且必须间歇"改成：
  **813/1384 假固定音没回来** / **354.5 族在** / **354.5 族常驻** / **2097 仍间歇、占空比 1/3**。
  167 通过 / 0 失败。

**电平是怎么定下来的**（记下来，省得下次再猜）：壳子对 354 Hz 和 2097 Hz 的增益差 ~17 dB，
所以不能按幅度直接换算。做法是先用已有的 2097（`amp 0.10` → 实测 −24.8 dB 相对 RMS）
当标尺，再迭代两轮：

| 轮次 | amp | v4x 实测 354.5（相对 RMS） | 目标 −21.7 |
|---|---|---|---|
| 1 | 0.14 | **−5.0** | 差 16.7 dB |
| 2 | 0.020 | **−20.2** | 差 1.5 dB |
| 3 | **0.017** | **−21.4 / −21.6** | ✅ |

新版对旧版的实际改变（20~26 s，等电平）：

| | 354.5 Hz | 709 Hz | 2097 Hz |
|---|---|---|---|
| v38（旧） | −45.0 | −35.1 | −24.6 |
| v43（新） | **−21.6** | **−26.2** | −24.6 |

⇒ 354.5 抬了 **23.4 dB**，709 抬了 **8.9 dB**。

## 4. 第 34 轮：固定音要不要加裙边？——**不用，问题是电平**

用户听完 v43：「固定音是不是也带宽裙边，现在这个太刺耳了」。先怀疑裙边，量了再说：

**固定音没有裙边**（近邻 3~12 Hz 与稍远 15~30 Hz 之差）：

| 对象 | 近 − 远 |
|---|---|
| 354.5 Hz（固定音） | **−0.5 dB** |
| 709 Hz（固定音） | **+1.4 dB** |
| 1498 Hz（固定音） | **−0.3 dB** |
| 大西 321.75 Hz（辅助音） | −0.0 dB |
| **大西 900.25 Hz（牵引线）** | **+8.4 dB** ← 只有它**有**裙边 |

⇒ **裙边是牵引线才有的东西**（逆变器调制扩散），**辅助机械是干净的机械音**。
所以 v43 的 354.5 族**不需要**加裙边。

**真正刺耳的是 2097 Hz 那条，它比实录响 25~28 dB。**同一口径：

| | 2097 线电平（相对 RMS） | 突出度 |
|---|---|---|
| 实录 9 条老 clip | −30.1 ~ −59.4（中位 ≈ −51） | −3.0 ~ +8.8 |
| 新录音 16~60 s | −28.8 ~ −53.6 | −2.5 ~ +12.7 |
| 我们（改前） | **−23.4** | **+28.6** |

`amp 0.10` 当初是**按耳朵定的**，从没跟"相对总 RMS"这个口径对过。
在 2 kHz（人耳最敏感）放一根比实录响 25 dB 的纯正弦，就是"刺耳"。

**改动：`amp 0.10 → 0.006`（−24 dB）**，实测：

| | 2~8 s | 22~28 s |
|---|---|---|
| 改前 | −22.7 / 突出 +45.6 | — |
| **改后** | **−47.4 / +21.9** | **−42.9 / +9.0** |
| 实录 | −30 ~ −59 | 突出 −3 ~ +13 |

22~28 s 那一窗（−42.9 / +9.0）正落在实录区间里。167 通过 / 0 失败。

## 5. 第 35 轮：**裙边是大西的，不该套在京急上**（用户指出的）

用户：「我们现在是在模仿京急列车啊，大西那个只是裙边的问题」。**对。**
"牵引线有裙边"这个结论整个是从**大西**量出来的，我却拿它给**京急**的模型加了 `--skirt -8.8,16`。

补量京急自己的线（同口径：近邻 3~12 Hz − 稍远 15~30 Hz，取最突出的 5 条平均）：

| 录音 | 最强 5 条的裙边指标 |
|---|---|
| 京急 新录音 32~34 s 平稳 | **+2.9 dB** |
| 京急 新录音 16~18 s 加速 | **+1.6** |
| 京急 late-300 | **+1.0** |
| 京急 cruise-36 | **+4.2** |
| 京急 accel-21 | **+0.7** |
| 京急 depart-16 | **+1.6** |
| **京急中位** | **+1.6 dB** |
| 大西 900 Hz 那条（当初的依据） | **+8.7 dB** |

⇒ **京急的线比大西细得多（差 7 dB）**。所以 `-8.8 dB` 这个值是**按大西定的**，对京急过头。

**但是**：这个指标**量不出裙边的"量"** —— 它是"近 vs 远"的**比值**，
而我们烘出来的裙边是一条 **1 Hz 间隔的梳齿**（噪声与循环等长），
近带和远带里都有它，**整体降电平不会改变这个比值**。实测就是平的：

| 干信号（无壳子/底噪） | top5 裙边指标 |
|---|---|
| 裙边 −8.8 | +4.1 |
| 裙边 −16 | +3.7 |
| 裙边 −24 | +5.1 |
| 无裙边 | +3.1 |

⇒ 指标在噪声里，**不能用来定裙边量**。而实录那边**根本分不出裙边和底噪**
（京急的线只比周围高 10~16 dB，大西那条高 35 dB 才分得出来）。

**所以按"没有证据"处理：京急不加裙边。**
（`--skirt` 这个开关留着，它在大西那种"线远高于底"的录音上是有依据的。）

另外顺带量到：**壳子自己会往线两侧加东西**，这是我们比实录"宽"的另一半原因：

| 配置（裙边 −16） | top5 指标 |
|---|---|
| 干信号 | +3.7 |
| + 传播/传导/失真 | +4.0 |
| + 非平稳调制（AM/拍频/纹理） | +6.0 |
| + 艺术化链 | +8.3 |
| 京急实录 | +1.6 |

其中 `beatHz 5.3 / beatDepth 0.15` 会在**每条线两侧 ±5.3 Hz 各加一个 −22 dB 的边带**。
为此给 `preview.mjs` 加了 `--nonstat <倍数>`（0 = 关掉 AM/拍频/纹理），
这样"裙边"和"调制"以后可以分开扫。

## 6. 第 36 轮：固定音的**频率抖动**

用户：「不可能直接定死在某个频率上的，应该会有抖动吧」。物理上对 —— 我们原来是**数学上钉死**的纯正弦。

**但要把两件事分开**：
- **裙边** = 同一时刻**并存**的一片噪声（改的是线的宽度）；
- **抖动** = **同一个音**在时间上慢慢飘（改的是它还在不在原位）。

### 先纠正我上一轮报的"±1%"

那个数是**跟踪器跳到路过的牵引线上**造成的：在 ±7 Hz 的窄带里逐 0.17 s 找峰，
一旦有牵引线扫过这个带，跟踪器就跳过去。证据是触边率 7~19%，而且**我们自己的纯正弦**
（理论上抖动 = 0）用同一方法量出 std 3.54 Hz —— 显然不是抖动。

### 可靠的口径：10 s 窗的 −20 dB 线宽

| 对象 | −20 dB 线宽（取最干净的窗） |
|---|---|
| **纯正弦理论值** | 0.25 Hz |
| 京急实录 354.5 Hz | 0.50 ~ 0.60 Hz |
| 京急实录 709 Hz | 0.50 Hz |
| 我们（无抖动，但过壳子） | 0.40 ~ 0.70 Hz |
| 我们（抖动 ±0.1%） | ~1.30 Hz（**偏宽了**） |

⇒ 可分辨的抖动 **≤ 0.1%**；而且**我们过完壳子的线宽本来就已经和实录一样（0.5~0.7 Hz）**，
所以再叠 0.1% 反而比实录宽。

**结论：抖动要加，但只能加很小**（物理上必须有，量级在 0.05% 以下，本方法分辨不出）。
另外这层宽度**有一部分是壳子自己造成的**，和上一节"壳子让线变宽"是同一件事。

### 实现

- `model.mjs` 的 `fixedTones` 条目新增 `jitterPct`（相对值，0.0005 = ±0.05%），
  `fixedTonePartials` 把它带出来；老 spec 不给 ⇒ 0，行为不变。
- `preview.mjs`：三条慢正弦（0.037 / 0.11 / 0.29 Hz，权重 1 / 0.6 / 0.4）归一化到 ±1，
  乘 `jitterPct` 去调**相位增量**（不加噪声、不改幅度）。相位由分音序号决定 ⇒ 可复现。
  选这三个速率是因为实录固定音的抖动谱峰落在 0.02~0.3 Hz（周期 4~50 s）。
- 新增 `--jitter <倍数>`：1 = 模型值，0 = 关掉，5 = 夸大到能听出来。

## 7. 第 37 轮：起步高频 = 2097 那一族，而且它是**按速度门控**的

用户：「线的宽度我认为还是需要再加一点，并且**起步的高频音不够**」。

### 定位：起步 HF 就是 2097 的 1/2/3 次

实录 16~20 s（刚起步）在 1~8 kHz 里最突出的三条线：

| 频率 | 突出度 | 相对 RMS |
|---|---|---|
| **2098 Hz** | **+26.2 dB** | −36.4 dB |
| **4196 Hz** | +22.8 | −44.0（其 2 次） |
| **6294 Hz** | +23.2 | −42.1（其 3 次） |

而同一批线在 **32~42 s 平稳段**的突出度只有 **+4.3 ~ +5.7 dB**（等于没有）。

⇒ **2097 不是"按时间随机通断的辅助机械"，而是"低速才有的东西"** ——
上一轮我按巡航段把它压了 24 dB，**顺带把起步这一层整个压没了**。

### 改法：同一个 2097 拆成**两条**，一条按速度、一条按时间

| 条目 | amp | count/decay | 门控 | 管什么 |
|---|---|---|---|---|
| 起步那条 | **0.042** | 3 / 0.70 | `untilF1: 45`（≈37 km/h 以上没了） | 起步的 2097/4194/6291 |
| 巡航那条 | 0.006 | 2 / 0.42 | 时间通断 7 s / 14 s | "有些巡航段偶尔也有 2097"（8 段实录里 3 段） |

**验收（口径：幅度 = |X|/(Σw/2)，再减窗 RMS）**：

| | 2097 幅度 | 窗 RMS | 相对 |
|---|---|---|---|
| 实录 16~20 s | −60.2 dBFS | −23.8 | **−36.4 dB** |
| **我们起步（改后）** | −55.4 | −18.9 | **−36.5 dB** ✅ |
| 实录 20~24 s | −51.5 | −16.7 | −34.8 |
| 实录 32~42 s | −70.4 | −13.6 | −56.7 |
| 我们 30~36 s（改后） | — | — | 突出度 +2.6/+6.3/+2.9（等于没有）✅ |

> 上一轮我在两个脚本里用了不同的归一化（一个带 ×2、一个不带），
> 一度把实录的 2097 报成 −30.4 dB。**统一口径后是 −36.4 dB**，上面这张表是唯一可信的。

`selftest.mjs` 的断言相应改成：2097 **分两条**（按时间一条 + 按速度一条）、
按时间那条占空比 1/3、按速度那条门控落在 20~40 km/h、起步那条比巡航那条响 ≥15 dB。
**169 通过 / 0 失败。**

### 线宽：给了三档让耳朵挑

`--skirt` 的第二个数就是宽度，烘了三版同电平对照：

| 段 | 设置 |
|---|---|
| 0.0~6.0 s | 无裙边 |
| 6.5~12.5 s | −12 dB / ±16 Hz |
| 13.0~19.0 s | −12 dB / **±28 Hz**（成品 v51 用这档） |
| 19.5~25.5 s | −12 dB / ±45 Hz |

（指标量不出裙边"量"的原因见 §5；宽度只能靠耳朵定，所以直接给对照。）

## 8. 还没解决的

- **固定音现在跟励磁一起被门控**（`preview.mjs`：`speedOk = it.f1 > 0 && …`）。
  也就是说**惰行时这层辅助音会一起消失** —— 对空调/压缩机在物理上是错的。
  要修就得给 tone 加一个"与励磁无关"的开关。本轮没动。
- 电平只按平稳段定了一个常数值，实录里它起伏 15 dB。要复现那个起伏，需要多段落统计 +
  每条 tone 各自的占空比，现在数据不够。
- 520 / 1246 / 1382 / 1498 Hz 那几条也像是固定音（频率也基本不动），本轮**没加**：
  它们的"不动"只在单段里验过，没做跨整段的复核，不想重犯 709 那次读错的错。
