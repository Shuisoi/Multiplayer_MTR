# 67 - C7 游戏内连挂/解挂：瞄准列车按 K

> 设计 §7 C7："游戏侧：对准连挂端点 → 提示 → 按键连挂/解挂；OP 指令"。
> 本片 = 模组侧交互 + 一个数据包；引擎侧**无需改动**（`couple`/`uncouple` 指令与全部闸门早已在 C4/C4b/C6 落地）。

## 交互

| 动作 | 条件 | 发送 |
| --- | --- | --- |
| **连挂** | 自己**正开着**一列车（在车上），瞄准**另一**列车（10 m 内、准星 25° 内） | `couple <我车> <目标车>` |
| **解挂** | 瞄准列车（自己那列或站在车外瞄准停着的车列）的**第 k 节**（k ≥ 2） | `uncouple <车> <k-1>`（切在瞄准那节之前） |

- 按键 **K**（`key.mmtr.couple`，与 G 进驾驶室、Y/U 车门、;/' 制动、←/→ 换向器不冲突）；
- 动作条提示：`按 K 连挂这列车` / `按 K 在第 k 节前解挂`；
- 瞄准点用每节车**自己的转向架世界坐标**（与渲染同一份数据），所以"瞄准哪一节"就是"切在哪一节之前"。

## 反馈（引擎是异步命令队列）

客户端发完请求后记下当前节数，2.5 s 后对比镜像里的节数：

- 变了 → `连挂 完成（2 → 3 节）`；
- 没变 → `未生效：检查调车授权 / 停稳 / 该处是否有车钩（引擎日志）`。

拒绝原因仍由引擎写进命令日志（`[MMTR-COUP] 连挂被拒: …`），所以所有闸门只有一个权威实现：

| 闸门 | 位置 |
| --- | --- |
| 调车授权（副显示） | `MmtrShuntAuthority`（C3a） |
| 同轨/0.3 m 连挂停车间距 | S1 许可式占用（C3b） |
| 两端都停稳、朝向兼容 | `MmtrCoupleSurgery`（C4/U5） |
| 切分只认车钩 | `mmtrCouplerAfter` + `uncouple <id> <车厢序号>`（C6/notes 62-63） |
