## 2. ★ 第一次跑：两条清障 fill 被整条拒 ⇒ 轨埋在山里

```
FAIL fill -2135 74 1385 -2004 97 1395 minecraft:air replace
     -> Too many blocks in the specified area (maximum 32768, specified 34848)
FAIL fill -2536 74 1385 -2283 94 1395 minecraft:air replace
     -> Too many blocks in the specified area (maximum 32768, specified 58674)
```

`gen_p2p` 当时只印一句"被拒 2 条"就继续往下铺轨了。**实测后果**（存档直读）：

| 位置 | 现象 |
| --- | --- |
| x=-2050 | 轨面 y=74 上是 `stone`、75/76 是 `dirt`、77 是 `grass_block` ⇒ **轨埋在地里** |
| x=-2350 | 74/75 是 `oak_leaves` ⇒ **树压在线上** |
| 全走廊 | 轨面以上仍有实体的采样点 **916 个**（x -2351..-2181 最高 **101**、-2065..-1917 最高 **101**） |

### 2.1 根因一：`read_tops` 读到**中间态**高度图（这条最隐蔽）

`build_plan` 的"路堑 / 隧道"判据要用**脚下 11 列的地表高度**。实测：施工时那里读到山头只有 **79**，
**落盘后真实是 119**（同一列、同一高度图 API）：

* ⇒ ① 把"该打**隧道**"判成了"该挖**路堑**"；
* ⇒ ② 清障盒被算成 24~45 格高 ⇒ 34k / 58k 格 ⇒ **超 `/fill` 的 32768 上限，整条被拒**。
  （两次读的差别在 `⑦` 那一步：区块是**本次 forceload 新生成**的，`wait_for_generation` 里那次
  flush 只覆盖了当时已完成的区块，最后一批的 heightmap 还没定稿。）

**修法**（`gen_p2p.py` ⑦ 步）：read → `save-all flush` → 停 2 s → **再 read，逐列取大**，
并在日志里点名"落盘后地表变了 N 列更高"。

### 2.2 根因二：`route_fills` 合并长盒时**从不看 32768 上限**

它把连续采样合并成一条 `fill`（省命令），但 Minecraft 单条 `/fill` 上限 **32768 格**，
超了**整条被拒**。**修法**：新增 `_emit_fill()` —— 沿 **x** 轴切片，保证每条 ≤ 上限；
`⑦` 出的产物里现在能看到 `-2536 … -2396` + `-2395 … -2283` 两块（原来是一块 58674）。
并在 `⑧` 步**被拒时打醒目告警**（"那几段一格没动，必须复核净空"）。

### 2.3 根因三：补跑没有入口

线路一旦接上，源端就不再是"自由端"，`resolve_source` 直接拒绝（"本工作流不从中间站引线"）
⇒ **修完工具没法原样重跑**。**修法**：`gen_p2p` 新增 `--src-axis/--src-center/--src-rail-y/
--src-along-lo/--src-along-hi`（手写源站几何，`--from` 只当标签；缺项就报错不猜）。

### 2.4 判据：`check_rail_above_deck.py` 新增**净空**一条

原来只查"路基顶 ≤ 轨面-1"（轨道沉进地基），**查不出"轨埋在山里"**。新增第二遍：
**轨面 .. 轨面+7（= `BORE_TOP_DY`）之间不得有实体**（`mtr:` 那一族跳过，断面上取 ±5），
**车站范围内不查**（站台/雨棚/立柱本来就在轨面以上 —— 第一版没排除，误报鸥湾西端雨棚边 2 处）。

## 5. 产物与用法

```powershell
# 常规：从自由端站接一条线（源端已不是自由端时会拒绝）
python sandbox\gen_p2p.py --from <站> --to X Z --rail-y Y [--mode auto|straight|shift|turn]

# 补跑/返工：手写源站几何（源端已被新轨占用时）
python sandbox\gen_p2p.py --from 鸥湾 --src-axis x --src-center 1390 --src-rail-y 74 \
    --src-along-lo -1910 --src-along-hi -1690 --to -2647 1390 --rail-y 74

# 验收（路基 + 净空两遍）
python sandbox\check_rail_above_deck.py --from 鸥湾 --to -2647 1390 --rail-y 74
python sandbox\verify_p2p_build.py --station-axis x --station-center 1390 --station-zfrom=-2757 \
    --rail-y 74 --conn-start=-1910,74,1387 --conn-start2=-1910,74,1393 \
    --base-rails 188 --base-lamps 162 --expect-rails 204 --expect-lamps 176
```
