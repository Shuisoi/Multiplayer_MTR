# 277 — 挂车模型 片 7：车钩力（折中版：机车 ↔ 车列一个钩）

日期：2026-09-26 · 设计：`docs/01-设计/非动力挂车-车辆模型与编组对象-设计.md`（片 7）

口径（规格 §6 + 设计文档的折中裁定）：自由间隙 **15–30 mm**、缓冲器**多段刚度**（初段软、尾段极硬防撞底）、
**迟滞吸能 60%–70%**；**先只做"机车 ↔ 车列"这一个钩**（两个等效质点），挂车之间仍视为刚性。

## 1. 为什么是"折中版"

引擎里一列车是**一节 `Vehicle` + 一个速度**。全多体（每节车一个质点、每个钩一个状态）要动世界/位置/镜像
三层；而规格 §6 的收益（起步逐节碰撞的冲动波）**主要来自机车与车列之间那一个钩**，所以片 7 只建这一个：
车头那节与它后面整列车列各当一个等效质点。

```
状态：d = 相对位移（正 = 钩被拉伸）、vRake = 车列等效速度
每拍：ḋ = vLead − vRake
      F_c = sign(d)·k(|d|)·(|d| − 间隙) + c·ḋ + F_y·tanh(ḋ/v_ref)
      a_rake = F_c / mRake        a_lead = (F_net − F_c) / mLead   ← 司机感受到的就是它
```

## 3. 三个踩出来的坑（都是"看着对、其实是假的"那一类）

1. **迟滞写成"刚度打折"⇒ 弛豫振荡**。第一版把"复原行程按 60–70% 折刚度"直接实现成
   `stiffnessAt(d, unloading)`。结果 `ḋ` 过零时力**跳变**，系统在载荷/卸载分支之间来回切：
   实测峰值钩力冲到 **833 kN**、车头加速度在 −6.4…+1.6 m/s² 之间抖，永远不收敛（极限环）。
   改成**连续的库仑迟滞**（`F_y·tanh(ḋ/v_ref)`：与相对运动反向的干摩擦）之后同一场景峰值 128 kN、
   稳态 1.000 m/s²。附带发现：吸能比 `8F_y/(kA)` 是**振幅的函数**（库仑圈是 4F_y·A），
   写成常数在小振幅上会给出 >100% 的荒谬圈面积 —— 规格的 60–70% 说的是典型行程上的数。
2. **参数自相矛盾 ⇒ 又一种极限环**：软段行程 40 mm 而"1 m/s² 拖 100 t 级车列的稳态变形"是 42 mm
   ⇒ 稳态正好落在两段刚度交界处，系统在两段之间来回切。修法：软段行程按"**稳态变形之上才撞底**"定
   （取 80 mm），并把这条**写进 `CouplerSpec` 的 javadoc 与配置注释**。
3. **刚性 ODE 不能靠外层子步**：钩的刚度 10⁶–10⁷ N/m，外层 50 ms 子步太粗（规格 §7 的原话）。
   钩内部按 **2 ms** 自己子步；并且 `step()` 必须返回**这一拍的平均加速度**（只返回最后一个内部子步的值，
   外层推进的量就与内部模型假设的量差一截，会往相对运动里泵能量 —— 实测稳态抖 ±0.2 m/s²）。

## 4. 判据（`MmtrCouplerTests`，4 条，全过）

```
起步：第一拍 1.87 m/s²（钩力 0 ⇒ 车头按自己的质量冲出去 = (mL+mR)/mL 倍刚体）
      间隙吃完第 3 拍 = 0.15 s（与手算 √(2·0.02/1.87) 一致）
      吃完那一下最低 0.55 m/s² ← **这就是"顿"**
      稳态（最后 40 拍平均）1.000 m/s² = 刚体；稳态钩力 84.8 kN = a·mR；峰值 128.6 kN（不断钩）
制动：钩力 −84.7 kN（压钩，车列推车头）；过渡段车头减速度最低 0.05 m/s²（明显小于刚体 1.00）
迟滞：40 mm 行程吸能 70%（规格 60–70%）；小振幅吸能比更大（库仑圈的性质）
刚度：间隙内 0、软段 2 MN/m、超过软段行程 20 MN/m（防撞底）；稳态变形必须落在软段内
零回归：不写车钩键 ⇒ getCoupler()==null，逐位等于片 7 之前
```

**全量：873 条、失败 3 条、跳过 6 条** —— 三条失败仍是预存在的世界存档漂移。

## 5. 已知边界（折中版，写在明处）

* **只在服务端算**：车钩口径不在镜像串里，客户端镜像仍按刚体积分，由权威快照每 tick 校正速度。
  真要做成两端逐点一致，得把钩参数进镜像（或进 `mmtrHandleSpec` 那一类字符串）——留给全多体那片。
* **挂车之间仍刚性**：长编组里的"逐节冲动波"没有（每节车一个质点才有）。
* **车列侧没有自己的牵引/制动力**：片 7 里车列是被钩拖着的**一个等效质点**（车列的闸由片 5 的逐车
  制动求和体现，但纵向质点只有一个）。
