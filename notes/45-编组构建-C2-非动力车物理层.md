# 45 - 编组构建 C2：非动力车在物理层落地

> 设计：`docs/01-设计/编组构建-连挂单元与连挂端点-设计.md` §7 C2。
> 目标（用户拍板）：**非动力车不能只是名字** —— 挂车必须真的"贡献质量与制动、不贡献牵引"。
> 前置：notes/44（C1 单元/端点/编组体纯数据）。

## 根因（C2 前的代码事实）

- `Vehicle.getMmtrComposition()`（`Vehicle.java:1660`）逐节车厢构造 `MmtrComposition.Unit`
  时把 `powered` **硬编码为 `true`**：机车 + 8 节挂车在物理上等于 9 节动力车；
- `MmtrCarSpec`（作业单/编组模板的车厢规格）**没有 powered / 车底类型字段**，作者无处声明；
- 整列只用**一个** ConsistType（`Vehicle.java:1596` 取 `mmtrDefaultConsistTypeId`），
  车厢级覆盖不存在。

## 实现（四层接线）

| 层 | 改动 |
| --- | --- |
| **持久化 schema** | `buildSrc/.../schema/data/vehicleCar.json` 增 **非必填** `mmtrPowered`（`"default": true`）与 `mmtrConsistTypeId`（`"default": ""`）。生成器对非必填字段用 `unpackBoolean/unpackString`——**只在键存在时覆盖**，故旧存档/旧车辆数据自动是 powered（不会因为"默认 false"把车变成死车）。生成类 `VehicleCarSchema` 里字段为 `protected boolean mmtrPowered = true;`（非 final，随车列序列化） |
| **运行时车厢** | `VehicleCar` 增 10 参构造（带 powered/consistTypeId）+ `getMmtrPowered()/getMmtrConsistTypeId()`；**8 参构造保留**并委托默认值 → 全仓 38 处既有调用零改动 |
| **编排 DTO** | `MmtrCarSpec` 增 `powered`（默认 true）/`consistTypeId`（默认 ""）+ JSON 往返；新增 `toVehicleCar()`（两处 spec→车列转换收敛到此）与 `toUnitCar()`（job → consist，C1 适配器） |
| **物理层** | `MmtrComposition.fromVehicleCars(cars, registry, fallbackType)`：逐车取自己的 powered 与 ConsistType（按 `mmtrConsistTypeId` 查注册表，缺失回退编组默认）；`Vehicle.getMmtrComposition()` 改用它，**去掉硬编码 true**。类型无法解析时返回 null（保持"无编组"旧行为，不抛异常打断 tick） |

## 测试（8 例）

- `MmtrCarSpecTests`（4）：powered/consistTypeId JSON 往返；**旧 payload 缺键 → 默认 powered**（零回归）；
  `toVehicleCar()` 携带元数据且几何不变；`toUnitCar()` 把空车底类型映射为 `null`（=继承）。
- `MmtrCompositionFromCarsTests`（4）：**机车+2 挂车 = 质量 4、牵引只来自机车**
  （`aggregate` 加速度 0.3×(2/4)=0.15，逐项断言）；车厢级车底类型覆盖编组默认；
  空车列/无回退类型 → 无编组、未知类型 → 回退不报错；
  **从车列构建的货运列车能用自己的制动缸刹停**（30 s 全制动速度 < 0.5）。

验证：`:engine:test` 全量 **385/0/2**（起点 377/0/2 → +8，**零新增失败**）。

## 遗留（显式记录）

- **数据侧**：dev 世界的 `mmtr-consist-templates.json` 里 `FRT-1`（非动力挂车）仍需显式写
  `"powered": false` 才会真的变成挂车——该文件是运行时数据、未入库，改动需重启 dev 服务端。
  仓库内 `config-example/consist-types.json` 是车底类型，不涉及车厢。
- **Web 编辑器**：编组车厢的 powered 勾选留到 C6（当前可直接编辑 JSON）。
- **空管初始化**：连挂瞬间挂车 pipe=0 属连挂操作语义，随 **C4**（真手术）落地。
