## 1. 这次的真正难点：车站模板写死了轨面 y=65

`gen_station.py` 原来把整套断面钉在 y=65：
`RAIL_Y=65`、`PLATFORM_Y=65`、`DECK_Y=(62,64)`、`CLEAR_Y=(65,80)`、
`CANOPY_BASE_Y=70`、`PILLAR_Y=(66,69)`、`LANTERN_Y=69`、信号柱/灯 `66/67`。

而爬坡段收在 **y=75** —— 直接建会整个埋进/悬空。

### 1.1 改法：把 Y 全部改成**相对轨面**（加 `--rail-y`）

```python
DECK_DY    = (-3, -1)     # 路基
CLEAR_DY   = (0, 15)      # 清障上限 = 轨面+15
CANOPY_DY  = 5            # 屋面起拱
PILLAR_DY  = (1, 4)
LANTERN_DY = 4
SIGNAL_POLE_DY, SIGNAL_LAMP_DY = 1, 2
```

`Station.__init__` 里按 `rail_y` 算出实例属性（`self.deck_y` / `self.clear_y` / …），
再把方法体里 33 行旧常量引用统一换掉。CLI 加 `--rail-y`（默认 65）。

**回归验收（关键）**：用 `--rail-y 65` 重跑既有三座站，与已建产物对拍：

| 产物 | 结果 |
| --- | --- |
| `station_ring_nw` fills / rails | **逐字相同 ✔** |
| `station_ring_nw` signals 的 16 条 `setblock` | **逐字相同 ✔** |
| `station_ring_ne` fills / rails / signals | **逐字相同 ✔** |
| 南北向样板站（`--axis z`）信号灯 | `(-45,66,800)` 柱 + `(-45,67,800)` 灯 `facing=south` —— **与实机一致 ✔** |

⇒ 参数化**没有改变任何既有行为**，只是多了一个自由度。
