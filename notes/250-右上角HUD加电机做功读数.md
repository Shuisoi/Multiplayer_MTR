# 250 — 右上角 HUD 加"电机做功"读数

用户口径（2026-09-23）：

> 在屏幕右上角 HUD 上面提示电机做功吧

## 1. 加了什么

右上角那块司机 HUD（`MmtrDriverHud`）在**速度**下面多一行：

```
速度      42 km/h
电机   300 kN · 6.40 MW
油门      牵引 96%
制动          运行
定速      160 km/h
换向          前进
```

- **出力 kN**：这一拍真正施加的轮周力（牵引为正、电阻制动为负），整数 kN；
- **做功 MW**：`出力 × 速度`（牵引为正、电阻制动为负 —— 电阻制动时电机在**过功**，符号必须能看出来），两位小数；
- 颜色：在牵引 = 牵引色（`#7FC4FF`）、在电阻制动 = 制动色（`#FF9900`）、都不出力 = 弱色。
  **"0 kN · 0.00 MW"本身就是信息**（手柄推到底还显示 0，说明联锁/保护按住了牵引）。

两个加载器（fabric / forge）都改了，两个文件的 `rows()` 各有一条分支（普通 / 被扣住）。

## 2. 数值从哪来（这一条是关键）

引擎新增两个读数（`Vehicle`）：

| 方法 | 含义 |
| --- | --- |
| `getMmtrMotorForceN()` | 电机出力（N，带符号） |
| `getMmtrMotorPowerW()` | 电机做功（W）= 出力 × 速度 |

- **三手柄车底**：用控制器交出的**实际施加**比例（`getLastTractionRatio()` / `getLastRheostaticRatio()`，
  即含牵引联锁、含建力延迟那一份）反算：`tractiveEffortN(比例, v) − 电阻制动力 × 衰减`。
  ⇒ 表上写的**就是车真的在出的力**，不是"手柄理论值"。
- **其它操纵模式**（有级/无级/空气制动）：没有单独的比例可读，用积分器这一拍真正返回的
  `DriveOutput` 净加速度 × 惯性质量折算（`mmtrLastDriveAccelerationMps2 × λm`，含阻力/制动，符号与量级都对）。

为什么必须"同一份数"：如果 HUD 自己再算一套，就会出现**"表说在出力、车却没动"**——
正是本仓最恨的那类现场（notes/216/247 都栽在"两处各算一套"上）。所以读数直接挂在积分器每步的
`DriveOutput` 上（`mmtrLastDriveAccelerationMps2`），HUD 只做单位换算与上色。

## 3. 在游戏里该看到什么（对表用）

现场编组 BR 101 + 2×p1（164 t，惯性 182 t，λ_eq 1.111）：

| 工况 | 期望读数 |
| --- | --- |
| 起步、满油门、干轨 | **300 kN · 0.00 MW**（有全力但速度还是 0） |
| 40 km/h（11.1 m/s） | 300 kN · **3.33 MW**（恒力矩段，功率随速度线性涨） |
| 76.8 km/h（21.3 m/s）= 折点 | 300 kN · **6.40 MW**（功率到顶） |
| 100 km/h（27.8 m/s） | **约 230 kN** · 6.40 MW（恒功率段，力随速度降） |
| 145 km/h（40.3 m/s） | 约 **159 kN** · 6.40 MW |
| 松油门惰行 | 0 kN · 0.00 MW |
| 电阻制动（手柄往负侧） | 出力为负、做功为负（≤ 150 kN 上限，按速度衰减） |
| 气制动按住（缸压未排空） | **0 kN · 0.00 MW**，哪怕油门推到底 —— 联锁在工作 |

折点就是 `P/F_max` = 6.4 MW / 300 kN = 21.33 m/s = 76.8 km/h，所以"76.8 km/h 之前力恒 300 kN、
之后力沿双曲线降、功率一直 6.4 MW"是这一行读数最直观的用法。

## 4. 与 TSW 那块表的对应

TSW 车里那块牵引表（notes/249 §5.5/5.6）满量程 80 kN，判断是**每轴/每电机**口径 ⇒ 整车满格 320 kN。
我们这一行给的是**整车**力（0–300 kN），所以两边读数要差 4 倍：TSW 表上 20 kN ↔ 我们这行 80 kN。
