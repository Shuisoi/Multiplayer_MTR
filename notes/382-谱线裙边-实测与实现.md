# 382 — 谱线裙边：实录量到什么、怎么实现、为什么现在还听不见

> 起因：用户看大西那段 39~41 s 的频谱，指出「这个好像并不是一条线，而是一个范围内的声音，
> 920 到 900 这里都有声音」。查下来他是对的 —— 由此发现了模型里缺的一层东西。

## 1. 实录里的谱线不是纯正弦

对 `来，再坐一次大西…VVVF 起步声`（602 s，mp3 128 kbps）前 150 s 的测量
（脚本：`sandbox/sound-studio/ref-daxi/`）：

**39.00~41.00 s（起步平台段）**

| 频段 | 电平 | 说明 |
|---|---|---|
| 900~902 Hz | −26.7 dBFS | 那条线本身 |
| 888~922 Hz（≈32 Hz 宽） | −45 ~ −52 dBFS | **裙边**，比两侧高 6~10 dB |
| 844~886 Hz | −55 ~ −62 dBFS | 低频侧背景 |
| 928~976 Hz | −53 ~ −62 dBFS | 高频侧背景 |

几条关键结论：

1. **线本身很纯**：3.5 s 长窗（bin 0.286 Hz）下 −10 dB 宽度只有 **0.86 Hz**，
   就是这个窗自己的主瓣宽度 ⇒ 本质是纯音。
2. **裙边是连续谱，不是离散边带**：去掉慢变趋势后起伏标准差 7.2 dB
   （纯噪声理论值 5.6 dB），自相关最大只有 0.11，找不到任何周期。
3. **裙边跟着线走**：线从 900 → 1013 → 1037 Hz 变，隆起也跟着搬
   ⇒ 是这条线自己的扩散，**不是固定在 900 Hz 的车体/结构共振**。
4. **对照**：322 Hz 那条辅助线的裙边只有 ±5 Hz（同样 2 Hz 一格量）。
5. 能量账：**裙边总功率只比线低 8.8 dB**（线 ≈2.14e−3，裙边 36 Hz 合计 ≈2.85e−4）；
   折成谱密度是**比线低约 24 dB/Hz**。

是真实调制扩散、还是 mp3 量化噪声？**倾向真实，但没证死**：
mp3 的 scalefactor 带在 900 Hz 约 70 Hz 宽、在 322 Hz 约 40 Hz 宽，
若裙边是编码噪声，322 那条也该铺开 ±20 Hz，实测只有 ±5 Hz。
要证死需要一个无损版本，现在没有。

## 2. 实现：`bake.mjs --skirt <总电平dB>,<半宽Hz>`

```powershell
node mmtr/tools/sound-studio/bake.mjs keikyu <out> --maxkmh 130 --skirt '-6,18'
```

- 定义：第一个数 = 裙边**总功率**相对**全部谱线总功率**的 dB；第二个数 = 半宽 Hz。
- 做法：与循环**等长**的白噪声 → 每根分音一个中心落在它频率上的 RBJ 常峰带通
  （`Q = f₀/(2·半宽)`）→ 按分音幅度加权求和 → 按总功率比归一。
- **为什么无缝**：白噪声缓冲长度 = 循环长度 ⇒ 本身周期；滤波器预热两遍再取用，
  记忆长度（Q≈25 时约 10 ms）远小于缓冲长度 ⇒ 第二遍起就是循环卷积稳态。
- 带 `--skirt` 才走这条路；不带时逐样本不变。
- `skirt` 会写进清单（`skirt: {db, halfHz}`），维持「音频 = 清单」这条不变量。

**参数选择的依据**：裙边是**按每根分音的幅度成比例**加的，所以
「总裙边功率 / 总谱线功率」这个比值**恰好等于**「某一根线的裙边功率 / 那根线的功率」。
实录量到的是后者 = **−8.8 dB**（13%）。所以**物理上对得上的是 `--skirt -8.8,16`**；
默认试听取 **−6 dB / ±18 Hz**（略强 3 dB，便于听出差别）。

## 3. 为什么现在还听不见 —— 真正的瓶颈是底噪

渲染 26~34 s（约 120~130 km/h，8 s），量「最强线与它 ±6~30 Hz 邻域」的对比：

| 变体 | 最强线 | 线突出度 | 远处底(±40~120 Hz) | 裙边−远处底 |
|---|---|---|---|---|
| v26 无裙边 · bed 1.0 | 305 Hz | −8.7 dB | −9.4 dB | +0.7 dB |
| v28 裙边 −6 · bed 1.0 | 305 Hz | **−8.7 dB** | −9.4 dB | +0.7 dB |
| v30 无裙边 · bed 0.45 | 324 Hz | −10.4 dB | −10.9 dB | +0.4 dB |
| v29 裙边 −6 · bed 0.45 | 323 Hz | **−9.2 dB** | −10.2 dB | +1.0 dB |
| v31 裙边 −6 · bed 0 | 324 Hz | −19.4 dB | −28.0 dB | **+8.6 dB** |

- `bed 1.0` 时加不加裙边**读数完全一样** ⇒ 裙边被噪声床彻底盖住。
- 把 bed 降到 0.45 才能量出 1.2 dB 的差别。
- bed 关掉，裙边立刻显形（+8.6 dB）。

把 bed 压到 **0.15**、只变裙边量，才是一条干净的单调序列：

| 变体 | ±4~25 Hz 邻域 | 远处底(±45~120 Hz) | 该窗 RMS |
|---|---|---|---|
| 无裙边 | −15.0 dB | −16.3 dB | −24.7 dBFS |
| 裙边 −12 dB | −14.4 | −15.8 | −24.7 |
| 裙边 −6 dB | −13.4 | −15.0 | −24.7 |
| 裙边 0 dB | −11.2 | −13.4 | −24.3 |

单档核对（`traction_p1_01550.ogg`，量"线带 ±2 Hz"与"缝里 >18 Hz"的功率比）：

| 设定 | 缝/线 |
|---|---|
| 无裙边 | 0.0002（就是 ogg 自己的底） |
| −12 dB | 0.0250 |
| −6 dB | 0.1010 |
| 0 dB | 0.3988 |

三个设定之间**严格成比例**（0.0250 / 0.1010 / 0.3988 = 1 : 4.04 : 15.95，
设定值 1 : 3.98 : 15.85）⇒ 归一化是对的。
绝对值比设定小（0.4 倍）是因为二阶带通滚降很慢，
裙边能量有一大截落在 ±18 Hz 之外，被算进"缝里"的分母口径不同 —— 不是 bug。

**实录的线突出度**（同样口径，取最强线 ±6~30 Hz）：

| 片段 | 线突出度 |
|---|---|
| cruise-36 | −26.0 dB |
| depart-16 | −25.4 dB |
| late-600 | −22.7 dB |
| idle-12 | −16.4 dB |
| late-300 | −14.5 dB |
| cruise2-56 | −13.8 dB |
| late-150 | −12.1 dB |
| late-450 | −9.7 dB |
| accel-21 | −9.5 dB |

实录落在 **−9.5 ~ −26 dB**（中位 ≈ −14）。我们 bed 1.0 时是 **−8.7 dB**——
**落在实录最差的那一端**。也就是说：

> 我们现在的噪声床不是"略多一点"，而是把谱线压到了实录里线最不突出的水平，
> 顺便把裙边这一层整个吃掉。

所以「加裙边」这件事本身不是独立可调的 —— **它被底噪卡住**。
下一步应该是先把 bed 压下来（或把线抬上来），再看裙边要多少。

## 5. 无底噪版（按实录参数：−8.8 dB / ±16 Hz）

```powershell
node mmtr/tools/sound-studio/bake.mjs keikyu sandbox/sound-studio/baked/kei18 --maxkmh 130 --skirt '-8.8,16'
node mmtr/tools/sound-studio/preview.mjs sandbox/sound-studio/baked/kei18 <out>.wav --ogg --shell cab --target 130 --bedgain 0
```

**`--skirt -8.8,16` 就是实录量到的参数本身**（每根线的裙边功率 = 那根线的 13%，±16 Hz），
不再是为了听出差别而加重的 −6。

26~34 s（约 120~130 km/h，8 s），「最强线 / 该窗 RMS」与邻域、远处底：

| 版本 | 线/RMS | 邻域 ±4~25 Hz | 远处底 ±45~120 Hz |
|---|---|---|---|
| v26 有底噪 · 无裙边 | +73.3 dB | −8.5 dB | −9.5 dB |
| v39 **无底噪** · 无裙边 | +72.3 | **−27.6** | −41.8 |
| v38 **无底噪** · 裙边 −8.8/16 | +72.0 | **−20.7** | −32.0 |
| 实录 accel-21 | +72.9 | −8.3 | −15.8 |
| 实录 late-450 | +76.3 | −8.5 | −20.5 |
| 实录 late-150 | +71.2 | −11.6 | −14.2 |
| 实录 late-300 | +72.3 | −13.8 | −16.7 |
| 实录 cruise2-56 | +70.5 | −14.3 | −11.6 |
| 实录 idle-12 | +72.0 | −15.6 | −15.8 |
| 实录 late-600 | +73.5 | −21.7 | −24.4 |
| 实录 depart-16 | +73.0 | −24.8 | −33.5 |
| 实录 cruise-36 | +78.4 | −26.4 | −26.4 |

三个结论：

1. **线的相对强度（线/RMS +72 dB）本来就和实录一样** —— 我们的问题从来不是"线太弱"。
2. **近邻域**：无裙边是 −27.6（比实录里最干净的 −26.4 还干净），
   加上按实录参数的裙边后是 **−20.7，正好落进实录中段**（late-600 是 −21.7）。
   ⇒ 裙边这一层的作用被量出来了，而且是**按实录的参数**做到的，不是靠加重。
3. **远处底**：我们还是 −32.0，实录中位约 −16.7 —— **还差 15 dB**。
   原因大概率是谐波密度：我们 120 km/h 时 f₁ ≈ 146 Hz，谐波间距 146 Hz，
   而实录那台车当时的间距远小于此，**裙边会互相叠起来形成连续底噪**。
   没验，但这是下一层要补的东西（"缝里也要有东西"）。

## 6. 开口的问题

代价（无底噪必然如此）：50~100 Hz 从 −24.3 dBFS 掉到 **−60.4**，整段 RMS −15.0 → −24.1。
所以这一版是"**裸电机**"版，用来听谱线/裙边那一层，不是成品。

顺带修了 `preview.mjs` 的一处误报：`--bedgain 0` 时"惰行段应当还有滚动噪声"这条
判据必然失败，现在按设计跳过并在日志里写明。

- 裙边半宽要不要随频率变？（实录只量到 900 Hz 一处，且 322 Hz 的裙边明显更窄）
- 我们模型里谐波间距是 f₁ ≈ 146 Hz（120 km/h），实录那台车当时的间距远小于此，
  所以实录的裙边会**互相叠起来**形成连续底噪，而我们的是**一根根分开的**。
  这可能是"我们听起来更干净/更电子"的另一半原因 —— 但没验。
- bed 与线的相对电平需要按实录重标一次（本轮只给了口径，没有定标）。
