# 308 · 环线北段车站两端信号灯（东西向）—— 照样板站 1:1 转置 8 盏

> 用户口径（2026-09-26）：**「车站两端的信号灯没摆」**。
> 承接 notes/306–307（车站本体：x=-500..-280，双线 z=1800/1806）。

## 1. 先读样板站的做法（不自创）

从存档读 `x=-40 / z=800..1020` 样板站的灯柱，得到**完整配方**：

| 项 | 值 |
| --- | --- |
| 灯柱列 | **站台边缘列**：`x=-45`（轨 -43 外 2 格）/ `x=-35`（轨 -37 外 2 格） |
| 灯位（沿轨） | 两端各两位：`z = 800, 801`（北端）与 `z = 1019, 1020`（南端） |
| y=66 | **`mtr:signal_pole`** |
| y=67 | **`mtr:signal_light_4_aspect_1[facing=…,is_22_5=false,is_45=false,power=0]`** |
| facing | `z=800` 朝 **south**、`z=801` 朝 **north**；`z=1019` 朝 **south**、`z=1020` 朝 **north** |
| 合计 | 2 列 × 4 位 = **8 盏** |

**规律**：同一端取相邻两位，**低坐标那盏朝 +方向、高坐标那盏朝 −方向**。

## 2. 转置到东西向车站

本站沿 **X** 走，于是整体转置（与 notes/306 的模板转置同一套映射）：

| 样板站 | 本站 |
| --- | --- |
| 沿轨方向 = Z | 沿轨方向 = **X**（+X = 东） |
| 灯柱在 x=-45/-35（东西两侧） | 灯柱在 **z=1798 / 1808**（南北两侧，= 站台边缘列，轨外 2 格） |
| 灯位 z=800,801 / 1019,1020 | 灯位 **x=-500,-499**（西端）/ **-281,-280**（东端） |
| facing south/north | facing **east/west** |

**facing 分配**（照"低坐标朝 +、高坐标朝 −"）：

| x | facing | 引擎角 |
| --- | --- | --- |
| **-500** | east | 270° |
| **-499** | west | 90° |
| **-281** | east | 270° |
| **-280** | west | 90° |

两列（z=1798 / z=1808）用**相同**的 facing —— 与样板站一致（同 z 的两列 facing 相同）。

产物：`sandbox/station_ring_nw_signals.txt`（16 条 `setblock`：8 柱 + 8 灯）。

### 4.2 各自守哪条轨（`signal why`，逐盏锚定本次查询）

| 灯 | 结果 | 守的轨 |
| --- | --- | --- |
| **-500,67,1798** | 守到 | **`(-500,1800)→(-280,1800)`（站台轨，220 m）** |
| **-500,67,1808** | 守到 | `(-500,1806)→(-280,1806)`（站台轨） |
| -499,67,1798 | 退回全部腿 | 站台轨（朝西，西侧无轨） |
| -499,67,1808 | 退回全部腿 | 站台轨（同上） |
| **-281,67,1798** | 守到 | `(-280,1800)→(-200,1800)`（站外东侧那段） |
| **-281,67,1808** | 守到 | `(-280,1806)→(-200,1806)` |
| **-280,67,1798** | 守到 | `(-500,1800)→(-280,1800)`（站台轨） |
| **-280,67,1808** | 守到 | `(-500,1806)→(-280,1806)`（站台轨） |

**两列各守自己那条轨**（z=1798 列 → 轨 z=1800；z=1808 列 → 轨 z=1806）✅
`-500,67,1798` 的 `signal why` 原文：

```
① 保护的轨 …（长 220 m），起点弧 0 m，朝向 (1.0, 0.0)
区间从弧 0 开始，东(+x) 走
[选腿] … 与朝向点积=1.0（灯管的那一侧有 1 条腿，都要守）… 结论=1 条腿都守
③ 结论：深度 0 → GREEN（绿）
```

### 4.3 两盏"退回全部腿"是**正常的**，不是 bug

`-499` 那两盏朝西，而**线在西端到头了**（x=-500 是现阶段线路终点），西侧本来就没有腿，
所以按规则"没有落在 FACING 那一侧的腿 → 退回全部腿"。

**样板站同样如此**：`(-45,67,801)` 朝北，而站台北侧只有 1 m，`signal why` 打的就是
「与朝向点积=-1.0（没有落在 FACING 那一侧的腿 → 退回全部腿）」。**这是既有惯例，不是本次引入的。**

> 以后线路往西延伸过 x=-500，这两盏**自动**就会守到西侧那一块 —— 现在留着是对的。
