# 07 移动世界 e2e 测试基建（M1 探针）— 进展与配方

目标：在引擎单测里重演 MTR 世界生成，让一辆车从 depot 发车并沿线路运行，
用于自动化验证 认领→驾驶→SPAD/保护→镜像→mmtr_couple/uncouple 世界层执行器。

## 探针发现（代码事实）
- Depot extends DepotSchema, schema javaExtends AreaBase<Depot,Siding>：
  - Depot 持 routeIds；writeRouteCache(routeIdMap) -> routes -> platformsInRoute。
  - Depot.tick() 驱动 SidingPathFinder（area 内 rails）并在成功后对每个 siding 调
    siding.generateRoute(platformsInRoute[0], 末位, 数量, cruisingAltitude)；
    siding 完成后 finishGeneratingPath -> generatePlatformDirectionsAndWriteDeparturesToSidings()。
  - siding 在 Siding#simulateVehicles：area != null 且 defaultPathData != null 且 vehicleCars
    非空 且 spawnTrain 时 new Vehicle(...) 放入 vehicleIdMap（发车需 departures/手动）。
- Siding.area 指向所属 Depot(AreaBase<Depot,Siding>)；area/child 接线在 AreaBase 里。
- Rail 工厂签名很长（曲线/超高/样式），轨道连通靠端点；SidingPathFinder 在 depot area rails 上寻路。

## M1 最小网络配方（待实现/验证）
1) 新 Simulator。
2) 建两站两站台 + 直轨平台 rail + 连接 rails；站台 rail 属性 isPlatform。
3) 建 Route（routePlatforms: A→B），加入 simulator.routes & depot.routeIds。
4) depot：setCorners 覆盖 siding/站台、setFrequency 全时段>0、addSiding?（AreaBase 提供）、
   simulator.depots.add(depot)、simulator.sync()。
5) 反复 simulator.tick() 让 Depot.tick 跑 SidingPathFinder 至 finishGeneratingPath；
   断言 depot.getLastGeneratedStatus()==SUCCESSFUL、siding 有 defaultPathData。
6) 断言首个 Vehicle 生成并 railProgress 前进（M2）。

## 第二轮发现（M1 配方收窄）
- **挂接是位置的**：Data#mapAreasAndSavedRails 按 savedRail.midPosition 落在 area 角点内 + 运输模式匹配
  自动设 Siding.area/Depot.savedRails —— 测试里只需 Depot.setCorners 包住 Siding 位置 + simulator.sync()。
- Depot.init()（writePathCache→savedRails Siding::init→写时刻表）；Depot.tick 每 tick 推进
  SidingPathFinder，成功→siding.generateRoute(首站台…)，完成→departures。
- Station(Data)/Platform(pos1,pos2,mode,data)/Route(mode,data)/RoutePlatformData(platformId) 均可直接构造；
  RuntimeTests 演示 station+platform 经 HTTP update 建实体；ArrivalResponseTests 演示 Route+RoutePlatformData 用法。
- 瓶颈收窄到两块：
  1) 真正 rail 网络（含 isPlatform rail、连通、speed/样式参数）+ 轨道位置与 platform/station 对齐；
  2) SidingPathFinder 起点（depot 区域内 siding 的 saved rail）→ 站台 rail 的可寻路路径。
- 下一步（M1 round2）：读 Rail 连通(addConnectedRail/端点匹配)与 Siding.generateRoute/finishGeneratingPath，
  以及 Platform 与对应 rail 的绑定(platform.savedRailId?)；随后在测试里首次组装“站台rail+直轨+折返”试跑。
