# 245 · S3 前半：轮轨黏着曲线 + 黏着上限（牵引力不再只由电机决定）

日期：2026-09-23 · 接 notes/243 的实施顺序，做 S3 的**可验证前半**：
把"牵引力"从"电机能给多少"拉回到"**轮轨能传多少**"。轮对角速度状态 / WSP / ASG 那半留到下一轮。

---

## 1. 新增 `AdhesionSpec`（`mmtr/physics`，纯函数）

```
μ(s) = μ_max · (s / s_crit)              0 ≤ s ≤ s_crit      ← 微滑弹性区：线性上升
μ(s) = μ_max · (1 − 8·(s − s_crit))      s > s_crit          ← 宏观打滑区：负斜率衰减
F ≤ μ_eff · N                                                ← 黏着上限（N = m·g）
```

- 环境轨面（规格 §4）：**干 0.37 / 湿 0.20 / 落叶·油污·黑冰 0.07**；
- 峰值滑差 `s_crit` 缺省 **2%**（真车 ASG 锁 1.5–2.5% 的中值）；
- **撒砂 ×1.30**（规格给 1.25–1.40）；
- 还有 `slipForEffort(力, 法向力)`：**要把这个力传下去需要多少滑差**（超过 `μ_max` ⇒ `MAX_VALUE`）——
  这是下一步 ASG 的现成输入。

## 2. 接线：`TrainPhysics` 的牵引取"电机上限 ∩ 黏着上限"

```java
public double tractiveEffortN(ratio, v) {
    return Math.min(traction.effortN(ratio, v), adhesion.maxTractiveEffortN(massKg * g));
}
```
`ConsistType` 增两个配置键：**`adhesionMuMax`（缺省 0.37 = 干轨）**、**`sanding`（缺省 false）**；
编组（`MmtrComposition.toConsistType`）沿用"说话那节车"的轨面条件。

**BR 101 的实机含义**（真车数据自带的印证）：300 kN 需要 `μ = 300 kN/(84 t·g) = 0.364`，
干轨 0.35–0.38 刚好够 ⇒ 干轨满牵引可用；**湿轨只能传 165 kN**（满手柄拿不到 300 kN）；
落叶 58 kN；湿轨撒砂 214 kN。

## 4. 遗留（S3 的后半 + 与规格的其它差距）

| 项 | 说明 |
