# 274 — 挂车模型 片 4：载重百分比 → 逐车质量

日期：2026-09-26 · 设计：`docs/01-设计/非动力挂车-车辆模型与编组对象-设计.md`（片 4）

用户口径（2026-09-26）：**载重需要有一个百分比来表示，并用于计算新的质量**；**分客车与货车两族**。

## 1. 口径

```
车底（ConsistType）给「载重能力」 payloadKg
车卡（VehicleCar / MmtrCarSpec）给「载重比例」 loadRatio ∈ [0,1]（片 1 已通路）
逐车质量  m = 整备质量 + loadRatio × payloadKg
```

**载重只影响质量**：惯性（λ·m）、黏着法向力随之变；**制动锚不动**、牵引力上限不动
（用户口径就是"用于计算新的质量"；空重车调整阀两段动作明确不做，设计文档 §6）。

## 2. 实现（一处折质量、两处读）

| 处 | 做法 |
| --- | --- |
| `ConsistType` | 新增 `payloadKg`（第 24 个构造参数，**缺省 0 ⇒ 老配置逐位不变**）+ `getPayloadKg()`、`loadedMassKg(比例)`、`effectiveMassForLoadKg(比例)`（不分配对象）、`withLoad(比例)`。`withLoad` 把载重**折进 massKg**、载重能力归零 —— 折而不是留比例，是为了让 `getMassKg()`（日志/镜像/用例都读它）与服务端真正在跑的物理是同一个数 |
| `MmtrComposition.Unit` | 新增 `loadRatio`（`fromVehicleCars` 从 `VehicleCar.getMmtrLoadRatio()` 填）+ `loadedType()`；`toConsistType` 逐车用 `loadedType()` 求和（质量/惯性/牵引/制动/阻力都取折过的），`totalEffectiveMassKg()` 走 `effectiveMassForLoadKg`（每 tick 的路径，不分配对象） |
| `Vehicle.mmtrRefreshConsistTypeFromCars` | **单节编组**也要折载重（单节不走等效车底那条路，notes/243 S1）—— 否则"一节重车"会按整备质量跑 |
| `config-example/consist-types.json` | `p1_trailer` 加 `payloadKg: 10000`（估算：满员 + 行李）；新增 **`freight_wagon`**（货车族：整备 24 t、载重 56 t、λ 按重车位 56 t 反推锚 ≈ 41 kN），并把 `cargotest`（包里已存在的 16 m 货运敞车模型）映射到它 |

## 3. 判据（`MmtrTrailerLoadTests`，5 条，全过）

```
一台 BR101 + 一节货车：空车 108 t / 半载 136 t / 满载 164 t
  起步加速度 2.434 / 1.966 / 1.649 m/s²           ← 单调 + 满载比空车低 32%
  100 km/h 全常用制动距离 330 m / 487 m            ← 同一份闸、质量多一半 ⇒ 1.48 倍
制动锚与牵引上限：载重 0 与载重 1 **逐位相同**（有意的取舍，钉在用例里）
withLoad：比例 0 返回原对象；比例 1 ⇒ 整备 = 总质量、载重能力归零、惯性/法向力跟着走；比例夹在 0…1
随包配置：p1_trailer 载重 10 t；cargotest → freight_wagon；BR101+2×货车 空车 132 t（2.017 m/s²）
          / 满载 244 t（1.127 m/s²）
零回归：`payloadKg` 不写 ⇒ 任何比例都不改质量
```

**全量：860 条、失败 3 条、跳过 6 条** —— 三条失败仍是预存在的世界存档漂移。

## 4. 已知取舍（写在明处）

* **空车会被"过制动"**：`freight_wagon` 的锚按**重车位**（56 t 制动重量）反推 ⇒ 满载 80 t 是
  0.49 m/s²（货车量级，对），但同一份锚在空车 24 t 上是 1.64 m/s²（偏强）。真车用**空重车调整阀**
  （P/G 位）切换 —— 那条不做。要修就先补"空重车两档制动重量"，是一个独立的数据片。
  选"重车位"而不是"空车位"的理由：装满的列车才是设计工况，而空车偏强至少方向安全（不会刹不住）。
* **Davis 的 A 项不随载重缩放**（`MmtrComposition.resistanceForceN` 的注里写明）：重车少了那点滚阻增量。
* 载重是**车的静态数据**（随车列持久化），不进气路串；连挂/解挂不动它。
