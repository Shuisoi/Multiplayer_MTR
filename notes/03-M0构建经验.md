# notes/03-M0 构建经验（2026-09）

## 关键：Gradle -P 参数必须加引号
在本机 pwsh 环境下 `-PminecraftVersion=1.20.4`（不带引号）会被吞掉点号变成 `1`，
导致 BuildTools `split("\\.")[1]` 抛 IndexOutOfBounds。正确写法：
    .\\gradlew.bat fabric:setupFiles fabric:build '-PminecraftVersion=1.20.4'
（任何含点号的 -P 值都要引号。）

## Composite 失败原因（已回退）
game 用 Gradle 8.14 + loom 1.10；engine 用 Gradle 9.5.1 + 新版 shadow/lombok 插件，
includeBuild 在宿主 Gradle 8.14 下不兼容（addVariantsFromConfiguration 等 API 缺失）。
=> 维持上游式集成：scripts/sync-engine.ps1 把 engine shadowJar 同步为
   game/libs/Transport-Simulation-Core-0.0.1.jar（改引擎后跑一次该脚本再构建 game）。

## 构建要点
- JDK21（game 的 BuildTools.javaLanguageVersion 为 17 目标，loom/engine 工具链 21；统一用 21 运行 gradle）
- fabric.mod.json 由模板生成（id=mmtr）；setupFiles 会在 fabric/src/main/java 下生成
  org/mtr/mod/generated/**、Keys.java、TranslationProvider.java 等（不入库，见 .gitignore 候选清单）
