## 1. 迁移配方（换模型 ≠ 改手感）

旧的 `A₀ / v_bp / a_制动 / 阻力 A,B,C`（全是加速度量纲）→ 力，取参考质量 `m₀`：

```
F_max = m₀ · A₀                     maxTractiveEffortN
P     = F_max · v_bp                maxPowerW          (v_bp = tractionBreakpointKmh / 3.6)
F_常用 = m₀ · serviceBrakeDecelerationMps2      serviceBrakeForceN
F_紧急 = m₀ · emergencyDecelerationMps2         emergencyBrakeForceN
A_N/B_N/C_N = m₀ · resistanceA/B/C              resistanceAN/BN/CN
m = m₀,  λ = 1
```

**这样换完，每一条曲线逐点相同**（`TrainPhysicsTests.legacyAccelerationParametersConvertWithoutChangingTheCurve`
就是它的可执行版本）—— 于是"换模型"和"调手感"是两件事，可以分开验证。

新 JSON 键（旧键**删除**，不留兼容读取）：

```json
{ "id": "br101_three_handle", "controlMode": "THREE_HANDLE",
  "massKg": 82000, "rotatingMassFactor": 1.06,
  "maxTractiveEffortN": 200000, "maxPowerW": 1900000,
  "serviceBrakeForceN": 120000, "emergencyBrakeForceN": 200000,
  "resistanceAN": 1500, "resistanceBN": 20, "resistanceCN": 3.0 }
```

镜像字段（`schema/data/vehicle.json`）同口径改名：
`mmtrMassKg / mmtrRotatingMassFactor / mmtrMaxTractiveEffortN / mmtrMaxPowerW /
mmtrServiceBrakeForceN / mmtrEmergencyBrakeForceN / mmtrResistanceAN / mmtrResistanceBN / mmtrResistanceCN`
（旧的 `mmtrTractionAccelerationMps2 / mmtrServiceBrakeDecelerationMps2 / mmtrEmergencyDecelerationMps2 /
mmtrTractionBreakpointKmh / mmtrResistanceA/B/C / mmtrMassRatio` **删掉**），
`VehicleSyncPatch.DYNAMIC_KEYS` 同步改名，`createMirrorConsistTypeFromSync` 改读新字段。
