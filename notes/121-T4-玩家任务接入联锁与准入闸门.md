# 121 - T4（一）：玩家任务接入联锁 + 无任务不得操纵

> 对应设计：`docs/01-设计/行车控制-任务联锁与行车许可-设计.md` §A-5 / §5.3 / §6（T4 前半）。
> 前置：notes/116–120（T1/T1b/T2/T3）。触发：用户 2026-09-14「一路把T做完吧」。

## 1. 修前：玩家执行的任务**根本没有接入联锁**

`Vehicle` 里两处申请点（自臂、每 tick 续期）的门都是
`mission.getExecutor() == AUTOPILOT && mmtrMotionAuto`，所以**玩家执行的任务**：

- 不规划、不发布 `MmtrRoute`、不申请道岔、不参与 SET 判定。

后果不是"少了个优化"，而是**任务做不下去**：玩家开车执行任务，到第一处道岔就撞上
"位置停在默认 0、没有任何东西给它授权"的物理闸门（notes/115 的闸门）。这正是设计 §9 里
"要求 A"写的那件事 —— 当时判断它"现在还没在代码里成立"，本片把它补上。

## 2. 交付

| 件 | 内容 |
| --- | --- |
| `mmtrMissionNeedsRouteSetup(mission)` | **自臂**该不该跑：AUTOPILOT **或** PLAYER |
| `mmtrMissionDrivesItsOwnRoute(mission)` | **每 tick 续期**该不该跑：`PLAYER` 或 `AUTOPILOT && mmtrMotionAuto` |
| `mmtrMotionSelfArmMission` 分叉 | 自动车照旧 `setMmtrMotionAuto(true)` + 停车目标；**玩家车只发布进路与授权，油门留给司机** |
| `mmtrPlayerRoutePublished` 闩 | 玩家车不设 auto / 停车目标，那两个当不了"已自臂"的标志 —— 没有闩会每 tick 重规划（幂等但刷屏）。任务终态时清掉 |
| `MmtrDriveAccess.taskAdmitsDriving(requireTask, hasLiveTask)` | **准入门槛**：无任务不得操纵。纯函数，便于直接测真值表 |
| `Simulator.mmtrRequireTaskToDrive` | 策略开关，**默认关**（真服务器上打开）—— 与 `mmtrDefaultPointsZero` 同一个模式 |

## 3. 本片的坑：两个判据**不能合成一个**

一开始我把两处都换成同一个 `mmtrMissionDrivesItsOwnRoute`，**八条既有用例立刻红**，
症状统一是"车没有自臂"。原因是一个**顺序**问题：

> **自臂发生在 auto 打开之前** —— 所以自臂的判据里**不能**要求 `mmtrMotionAuto`
> （自动车此刻 auto 还是关的，于是永远轮不到自臂）。

拆成两个判据之后全绿。这个顺序不是细节，是这一片的要点：
"该不该为这个任务建进路"与"进路是否正在推进、需要续期"是**两个问题**。

## 4. 验收

- 新增 3 例（`MmtrPlayerMissionInterlockTests`）：
  - `aPlayerMissionStillGetsItsRouteAndTurnoutsButNotTheThrottle`（①：玩家任务也发布进路、道岔真授权给它、进路 SET，而 `isMmtrMotionAuto()` **仍为 false**）
  - `drivingWithoutATaskIsRefusedOnlyWhenThePolicyIsOn`（② 真值表四条）
  - `theGateIsOffByDefaultSoExistingBehaviourIsUntouched`（② 默认关 ⇒ 既有行为不变）
- 全量引擎：**564 通过 / 0 失败 / 4 跳过**（T3 后 561 + 本片 3 例，**零新增失败**）。

夹具踩坑两条，记下来免得重蹈：
1. **车站要先于站台建立**，反过来站台挂不上车站；
2. 站台那根轨必须是 **`Rail.newPlatformRail`**，普通 `through()` 建的轨挂不上。

## 5. 一处刻意没写成的断言（说明为什么）

"策略开 + 有任务 ⇒ 能操纵"这条**没有写**：那道闸过了之后还有原有的
"坐在司机座 + 持钥匙 + override 归属"三关，而夹具里没有骑乘的玩家，
于是开与关两种情况**都返回 false —— 断言不具区分度**，写了等于自我安慰。
有区分度的是判据本身（真值表）与"默认关"这个事实，两者一起才说明"闸门存在且不改变现状"。
要补"有任务就能操纵"，需要一套真骑乘者的夹具，那是另一件工作。
