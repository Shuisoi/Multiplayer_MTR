# 390 · 起步"断断续续"：三个根因（含两个真 bug）

用户口径（第 44 轮）：「**开头起步还是有点颗粒感，感觉断断续续的**」

这一轮先试了 5 个标量判据（漂移 / 幅度调制 / 帧率纹波 / 包络跳变 / 周期性凹陷），
每个都能给出结论但**没有一个能指出形态**；最后靠"全带 RMS 逐 20 ms 打表"才看出
**凹陷间隔的公共周期是 0.06 s（≈16.7 Hz）**，顺着它找到下面三条。

---

## 1. ★ 真 bug：等功率交叉淡化其实**不是**等功率

`preview.mjs` 换档时的代码是：

```js
const gain = Math.cos(progress * Math.PI / 2) * prev.volume;   // 旧档 1 → 0 ✓
out[s] += readAt(prevData, ppos) * gain;
// 而新档在**另一个循环**里照常加满：
//   out[s] += readAt(data, pos) * item.volume                // 恒为 1 ✗
```

新档没有从 0 涨上来，所以淡化区间的总功率是 **`cos²(θ) + 1`**：
θ=0 时 2、θ=45° 时 **1.25（+0.97 dB 的鼓包）**、θ=90° 时 1。
**起步段每 ~200 ms 换一次档 ⇒ 每 200 ms 鼓一次。**

**修法**：新档在淡化区间内也按 `sin(θ)` 从 0 涨到 1（与 `cos` 互补 ⇒ 功率恒为 1），
即在写完之后把"满音量那一份"撤掉、按 `sin` 写回。

## 2. ★★ 主因：`bake.mjs` 的 **20 Hz 硬截断**（这才是"断断续续"）

```js
if (p.hz < 20 || p.hz > spec.maxPartialHz) {
    continue;                       // ← 整根丢掉
}
```

起步时 **f₁ ≈ 4~9 Hz**（起動加速度 3.5 km/h/s），于是 `n·f₁` 里有**一大排分音紧贴
在 20 Hz 这条硬线上**（f₁=6.7 时 3/4/5/6 次谐波 = 20.1 / 26.8 / 33.5 / 40.2 Hz）。
速度一动，它们就**依次跨过 20 Hz 被整根打开/关闭** —— 每跨一根电平跳一次。

**而实测实录（京急 2100 形起步，notes/387）从 17.5 Hz 起就是连续的**，
没有这条断崖可跨 ⇒ 断断续续是**我们的合成方式**造出来的，不是电机本身。

**修法**：新增**共享导出** `lowFloorGain(hz)`（`model.mjs`）——
10 Hz 以下为 0、10~24 Hz 线性渐入、24 Hz 以上为 1。

★ 做成共享函数是因为 `hz < 20` 这个判据原来在 `model.mjs` 里散着 **3 处**、
`bake.mjs` 里 1 处 —— "两处各写一份"正是这个项目反复踩的坑
（`humWeight` 那次就是"模型说一套、烘出来另一套"）。现在只有一个来源。

## 3. 另外两处已改（上一轮）

- `nonstationary` 整个删掉（notes/389，用户口径"把这个删了"）；
- `nonstationary()` 补 falsy 守卫。

## 4. 效果（全带 20 ms RMS，起飞起始段的相邻跳变）

| 指标 | v64（三条改动前） | **v65（改后）** |
|---|---|---|
| 0.3~4 s：跳变 >3 dB | 66 / 183 | **50 / 183** |
| 0.3~4 s：最大单跳 | **9.9 dB** | **7.6 dB** |
| 0.3~4 s：std | 2.35 dB | **2.06 dB** |
| 4~12 s | 54 / 399 · 6.0 dB · 2.08 | **54 / 399 · 6.2 dB · 2.08**（不变） |
| 20~40 s | 24 / 1000 · 4.8 dB · 1.34 | **24 / 1000 · 4.8 dB · 1.34**（不变） |

**4 s 之后三个窗逐个数字都不变** ⇒ 这条改动确实只作用在起步那条断崖上，
不存在"把别处也改了"的回归。

⚠ 起步段仍有 **50/183（27%）>3 dB** 的跳变 —— **没有归零**。
剩下的部分来自换档处两档相位不相关（`preview.mjs` 的 `phase` 是**每档独立**的），
这一条**未修**（要修得让新档继承旧档的相位，属于较大改动）。

## 5. 落实

- `model.mjs`：新增导出 `lowFloorGain(hz)`；3 处 `hz < 20` 调用点改为用它并**乘上增益**。
- `bake.mjs`：改为 `import { lowFloorGain }`（删掉本地的 `lowFade` 副本）。
- `preview.mjs`：等功率淡化修成 `cos`/`sin` 互补。
- `selftest.mjs`：把锁住旧行为的 `分音全落在 [20, 8000] Hz` 改成
  `[10, 8000] Hz（10~24 渐入）`，并补 3 条 `lowFloorGain` 纯函数用例
  （10 Hz 及以下为 0 / 24 Hz 及以上为 1 / 17 Hz 恰为 0.5）。
  **188 通过 / 0 失败。**
