# 385 — ★ 一个被漏掉的前提：参考录音那列车是**機器更新車（IGBT）**，不是西门子 GTO

## 1. 触发的线索

用户：「有个关键的忘了，这个车是京急2100系」。

顺着查参考录音的文件名：

```
【4K前面展望】…京急線 横浜→品川 - 1.ブルスカ2100形快特 120km_h爆走！前面展望(横浜→品川…
```

`ブルスカ` = **ブルースカイトレイン**（KEIKYU BLUE SKY TRAIN）的圈内简称。

## 2. 证据（两个独立来源）

**① 鉄道ファン railf.jp，2015-03-11**（[链接](https://railf.jp/news/2015/03/11/174000.html)）：

> 2015（平成27）年3月10日，京急2100形**2133編成**が更新工事を終え京急ファインテック久里浜事業所から出場し…
> 「KEIKYU BLUE SKY TRAIN」への塗装変更，フルカラーLED表示器への交換，
> **東洋電機製インバータへの変更**などが確認されています。
> **なお、今回の更新でシーメンス社製のいわゆる「ドレミファインバーター」を備えた2100形は消滅しました。**

**② 乗りものニュース，2021-06-30**（[链接](https://trafficnews.jp/post/108487/2)）：

> この「歌う電車」を採用した日本の鉄道車両は**京急2100形・新1000形電車の計19本**、
> JRのE501系電車の8本だけにとどまり、これらの車両も、**機器更新で「歌わないインバーター」に交換**されていきます。
> …IGBTは…特に「磁励音」を人間の耳に聞こえる周波数帯より高くできるのがメリットです。

**③ 日文维基「主要諸元」**（经 [weblio 镜像](https://www.weblio.jp/content/%E4%BA%AC%E6%80%A52100%E5%BD%A2%E9%9B%BB%E8%BB%8A?dictCode=WKPJA)）：

| 編成重量 | **229 t** |

## 3. 结论

**`SPEC_KEIKYU_2100_GTO` 建的是"更新前"的西门子 GTO 车；而参考录音那列（ブルスカ = 2133編成）是
更新后的东洋电机制 IGBT 车。** 两者是**同一形式的不同世代**，声音机理不同。

## 4. 这一下解释了三件一直挂着的事

| 现象（我们的实测） | 原解释 | **IGBT 解释** |
|---|---|---|
| 2097 Hz 线**纹丝不动**（+0.1 / −0.7 Hz/s）而列车在加速 | "辅助机械"（压缩机/SIV/风机） | **异步段载波**：IGBT 低速段载波固定在 ~2 kHz |
| 4195 / 6294 / 8392 = 1:2:3:4 次，**几乎等高**、一直到 8.4 kHz | "像脉冲串，不像衰减谐波列" | **PWM 载波的高次谐波**（本来就该是梳齿） |
| 门在 **24.2 s（25.4 km/h）** 干脆关掉、且 32~42 s 完全没有 | "速度门控的辅助音" | **异步 → 同步 切换**（同步后载波 = 整数 × f₁，不再固定） |
| 我们 300~3000 Hz 缺 ~10 dB（用户已选 A 保持现状） | "壳子太暗 / 参考是手机录音" | **真实声源是 2 kHz 载波系，不是 175~400 Hz 的 GTO 载波** |

⇒ 那条记成"辅助机械"的 **2097 族，很可能就是这列车逆变器的载波本身**；
而 `carrierTable`（175–400 Hz / 9 档「ドレミファ」）在这个录音里**根本不该出现**。

## 5. 裁决（用户，第 39 轮）：**走 A —— 建更新車（東洋電機 IGBT）**

不论走哪条，**官方诸元（229 t / 3,040 kW / 3.5 km/h/s / 歯車比 5.93）对两代都成立**，
已于第 39 轮写进 `SPEC_KEIKYU_2100_GTO`（名字待改）。烘焙复核：
`k = 1.2193 Hz/(km/h) · 折点 48.6 km/h`，行程全长 105.4 s → **129.3 s**（功率砍半的必然结果）。

## 6. ★ 更新車的载波：量到哪一步，卡在哪一步

### 6.1 素材：全带语谱图

`sandbox/sound-studio/ref-kei120/kei120-16-50-spectro.png`（16~50 s，0~9 kHz，
每列减 40% 分位以压掉宽带底）。一眼看到：

- **17~25 s**：2097 / 4195 / 6294 / 8392 Hz 四条**水平亮线**（固定，列车在加速）。
- **~28 s 起**：一条**向上爬的曲线**，约 4.0 kHz（28 s）→ **7.0 kHz（44 s）**，然后**压平**。
- 一条全天都在的 ~8.8 kHz 水平线；以及 175 / 400 Hz 附近的固定线。
- **500 Hz 以下是一整片宽带**（没有线）。

### 6.2 那条上行脊线（`sandbox/tmp/ridge.py`）

| t (s) | 脊线 (Hz) | 突出度 (dB) |
|---|---|---|
| 35.0 | 4928 | +16.2 |
| 37.0 | 5432 | +14.8 |
| 39.0 | 5936 | +14.1 |
| 41.0 | 6387 | +15.4 |
| 43.0 | 6789 | +12.8 |
| 44.0 | 6961 | +12.3 |

平滑单调上升、然后**在 ~7 kHz 压平** —— 这正是"载波随转速上升、撞到上限被钉住"的形状。

### 6.3 但 **p（分周数）没定下来** —— 四种办法都试过

| 办法 | 结果 | 为什么不够 |
|---|---|---|
| 匹配滤波扫 p（`sync_p.py`，24~50 s） | 所有 p 得分只有 **4.4~5.8 dB**，无赢家 | 脊线只存在 8 s，用 26 s 的中位数摊平了 |
| 脊线 / f₁ | 随速度从 **61 漂到 66**（−7%） | 依赖**假设的加速度 3.5**；换成 f₁ 或速度归一都同样漂 |
| 脊线自己的**边带间距**（`sideband.py`） | 附近是 **20~35 Hz** 的密线，**不是**预期的 ~85~100 Hz | 没能从音频里独立读出 f₁ |
| 整段**梳齿自相关**（`comb_f1.py`，16 个窗） | 间距聚在 **14.8 / 16.2 / 17.5 / 18.8 / 20.2 Hz**，且不随区段变 | 落在 FFT 栅格（df = 1.346 Hz）的低端，判不出是不是真 f₁ |

**结论（诚实）**：现在只能说"更新車的载波在 ~55 km/h 以上是一条随速度上升、约 7 kHz 封顶的线"，
**说不出它是 f₁ 的多少倍**。原因很直接：**我们没有任何独立于加速度假设的速度基准**
（录音里没有 GPS/速度计，只有声音）。

### 6.4 下一步（把 p 钉死需要的东西，按性价比）

1. **找一段真正的匀速**：匀速时 f₁ 与载波都恒定 ⇒ 用 8~10 s 长窗可以把梳齿间距与载波频率
   都量到 0.1 Hz，`p = 载波/间距` 一次读出。需要先在整段录音里定位匀速段
   （目前只在 16~60 s 有解码好的数据，其余要靠 ffmpeg 现解）。
2. **用 横浜→品川 的站间距离/信号限速**重建速度曲线，作为独立基准。
3. **查东洋电机制 IGBT 的分周表**（若京急 2100 更新車的 pulse 方案有公开资料）。

⚠ 在 p 定下来之前，**不要编一个载波表** —— 那正是本项目一直避免的"宁可缺一族，也不要编一个频率"。

## 7. 用户听感裁决：**把 4000 Hz 及以上直接砍掉**

第一次口径是「削减高频音」，我按**衰减**做了一版（`--hfcut <dB>` 去加深 ⑥b「去刺」），
实测 6~9 kHz 各减 7.3 / 11.3 dB。**用户否掉了**：

> 「不对的，我认为应该**直接把 4000 及以上高频砍掉而不是降声音**。」

⇒ 改成真正的**陡峭低通**。两者是不同的事：

| | 做法 | 性质 |
|---|---|---|
| ⑥b「去刺」 | 把 1800~4800 Hz **调小**（静态 −3.5 dB + 动态 −4 dB） | 降音量；而且**盖不到 6294 / 8392** |
| **终级低通** | 4 kHz 以上**没有了**（八阶 Butterworth，−48 dB/oct） | 真正的截止 |

### 7.1 实现

- `shell.mjs` 新增纯函数 `butterworthLowpass(x, fc, sampleRate, order)`（八阶 = 4 个双二阶级联）。
- cab 预设新增 `finalLowpassHz: 4000`。
- `preview.mjs` 在**终归一之前**作用到整条 `mix`（含底噪）上；`--hfcut <Hz>` 可覆盖，
  `--hfcut 24000`（≥ Nyquist）等于关掉。

**⚠ 必须是最后一级**：壳子里的暖化（并联 tanh ⇒ 偶次谐波）与饱和都会**重新生成高频**，
把低通放在链中间等于白做。这条是这一轮最容易搞错的地方。

### 7.2 实测（0.5~4 s 窗，频带能量 dB，只比差值）

| 带 | 无低通 | **v58（4 kHz 八阶）** | 差 |
|---|---|---|---|
| 300~1000 | 49.6 | 49.6 | **0** |
| 1000~3000 | 35.3 | 35.4 | +0.1 |
| 3000~4000 | 33.1 | 33.1 | **0** |
| 4000~6000 | 18.9 | 13.0 | −5.9 |
| 6000~9000 | 16.1 | **−16.8** | **−32.9** |
| 9000~16000 | 0.7 | −17.0 | −17.7 |

单频点（八阶的理论值，`butterworthLowpass` 自检逐条盯着）：
3.5 kHz **−0.6 dB** · 4 kHz **−2.9** · 5 kHz −15.6 · 6.3 kHz **−34.5** · 8.4 kHz **−53.2**。

### 7.3 又一次"占比看不出来"

三档的 `<500 Hz` 占比都是 **97.6%**、3000~8000 都是 **0.0%** —— 高频本来就只占总能量千分之几。
**判据必须用绝对电平/频带能量，不能用占比。** 这条在第 38 轮已经踩过一次，这里再记一次。
