# 99 - ① 区间式信号 × 道岔：区间入口停车（岔权未获则停在信号前）

> 承 notes/98（B3b）。用户 2026-09-10 拍板按 ①→②→③ 顺序继续。
> 背景实测（notes/97/98）：本世界 134 轨 / 130 节点，道岔（≥3 度节点）**只出现在轨的两端**（0 根轨穿过内部节点）；
> 13 根轨两端都是道岔。"区间里塞多个道岔"在数据模型里不存在——咽喉 = 多根轨/多个区间串起来。

## 1. 问题（本片要修的不一致）

B2 之后 S1 停在区间边界，但**边界只认占用**：如果下一区间（= 一整个闭塞分区）的**出口是道岔**而列车没有岔权
（无人工位、无授权、无目标），列车会**开进这个区间、一直开到道岔前**才由 walker `haltedAtAuthority` 停住。
后果两条：

1. 这个区间（含咽喉）被无谓占用，后车进不来；
2. "灯红 = 车停在灯前"不成立：灯保护的正是这个区间，车却已经开进去了（手动司机确认 AWS 后更可以顶着红灯开到岔前）。

## 2. 交付

| 件 | 内容 |
| --- | --- |
| 岔权前视 | `MmtrMotionPosition.wouldHaltAtForkOn(Rail)`（纯查询）：若现在改上 `rail`，它的**远端节点**有后继但选不出腿（无人工位 / 无授权 / 无目标匹配）→ true。两个 walker 各自实现（`MmtrMotionWalker` 用 enteredFrom/ahead，`MmtrConsistWalker` 按行进方向取 entry/exit），选举输入就是它们自己的 branches/authority/target，不会与 `advance` 走偏 |
| S1 规则 (3) | `Vehicle.nextSectionAuthorityStopM()`：找出列车**即将进入的那个区间**（同轨下一段，或下一根轨的入口区间）；若该区间**一直走到轨端**且远端是选不出腿的道岔 → 停在该区间的入口边界（= 保护它的那架灯）前 `MMTR_BLOCK_NODE_EPS_M`。调车授权覆盖该轨时豁免（许可式作业） |
| 不停车的情形 | ① 即将进入的区间在轨中段就被灯切断（它的出口不是岔）→ 允许进入、停在那架灯前；② 列车**已经在**"出口是岔"的区间里（灯已过去）→ 保持原行为，开到道岔前等；③ 岔已有人工位/授权/目标 → 不触发 |
| 不会死等 | `replenishForkRequests`：处于 ① 造成的区间停车时，**下一个道岔**的申请不再受 120 m 接近窗口限制（否则列车停在一个 187 m 区间的入口，永远进不了窗口、申请不出去 → 死等）；仍然只申请"下一个"道岔，不预先占整条进路 |
| 可观测 | 停车日志改成 `block stop Xm (block ahead ends at an unset turnout|block ahead occupied, waiting)`；`interlock` 报告首行加 `blockHeld=` |

## 3. 期望值变化（本片**改变**了既有行为，逐条记录）

`MmtrVehicleMotionRunTests.motionVehicleHaltsAtUnsetForksAndFlipsLiveAcrossBoth`：第二个岔（node1）未设时，
列车原来开到 `rBeyondA`（含岔的区间）的末端 ~60 m 才停、`haltedAtAuthority()=true`；

设岔后同一列车继续穿过去岔进 `rD`。用例注释已写明原因。

## 4. 用例（新增 2 例，`MmtrSectionAuthorityStopTests`）

- `aTrainIsHeldAtTheSignalBeforeTheBlockThatEndsAtAnUnsetTurnout`：Y→W→X→岔{S|D}，岔未设 → 停在 **W 末端**
  （20−0.001 m），不在 X 里、`haltedAtAuthority()=false`、blockHeld=true；60 tick 保持不动；设岔后**无需新指令**继续进 X、过岔到 S。

## 6. 已知边界与下一步

- **实机触发面**：真实服务端 `mmtrDefaultPointsZero` 把每个道岔预置成人工位 0（自动走直股），所以自由驾驶时 ① 基本不触发；
  它真正生效的场景是**任务的岔权被清空/排队中**（mission arm 把自己进路的道岔行置 -1，靠授权走）——此时列车会停在**含岔区间的入口**而不是开进去等，并提前把岔权申请发出去。
- **显示侧的一处不一致（记着）**：自由驾驶（无进路）时，① 让列车停在一架"占用链为绿"的灯前（因为没有进路 → 显示退回占用链）。
  任务/进路场景没这个问题：进路 PENDING 时入口区间本来就是红（S5/A2）。要彻底消掉，需要"无进路但有道岔在前 → 灯显危险"的显示规则，属下一片（④ 显示层）讨论。
- **② 岔区清限/侧面防护**（下一片）：区间边界=节点，车尾一出节点占用就"空"，侧冲进路可以被设到同一节点；要给节点加清限点或把岔区当小区间。
- **③ 占用锁闭收尾**：`MmtrMotionWalker`（非编组体）仍是头部越岔即释放，要统一成车尾清岔。
