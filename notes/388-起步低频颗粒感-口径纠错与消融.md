# 388 · 起步低频"颗粒感"：诊断、口径纠错与消融

用户口径（第 42 轮）：「我怎么觉得现在**起步低频部分有点颗粒感**呢」

这一轮的结论分三块：**① 一个口径错误（我连犯三次）**、**② 消融实验的结论**、**③ 没解决的根因**。

---

## 1. ★ 口径纠错：量"带内包络起伏"不能用 20 ms 窗的 FFT 置零

要判一个带里的包络稳不稳，**必须先把该带滤出来，再做时域 RMS 包络**。
我前两版都是"每 20 ms 做一个 FFT、把带外 bin 置零、算 RMS" —— **错的**：

- 20 ms 窗在 **20~120 Hz** 里只有 **5 个频率 bin**，窗长比周期还短；
- 谱泄漏把能量灌进低频 ⇒ **把"帧率纹波（30~300 Hz）"读成了"漂移（<3 Hz）"**。

后果是**结论直接反过来**：

| 口径 | 20–120 Hz 漂移 | 30–300 Hz（帧率） |
|---|---|---|
| 错（20 ms FFT 置零） | 0.0889 | **0.0000** |
| 对（30 ms 时域 RMS，5 ms 步进） | 0.1003 | **0.0007** |

错口径告诉我"控制帧率完全无罪"，对口径下帧率纹波**也**确实只有 0.0007（可以排除），
但对口径的"漂移"量级与分级完全不同 ⇒ **中途我基于错口径说过的
"补平梳齿没改善、所以不是梳齿形状"这一步仍然成立，但"漂移 5.5 倍"那个数不可信**。
正确数是 **成品 0.105 / 干源 0.083 / 实录 0.016**。

⚠ 记进教训清单：**窄带包络分析，窗长必须 ≥ 带内最低频的 3~5 个周期**；
20~120 Hz 至少要 30 ms，5 Hz 级要几百毫秒。参见 notes/384 §8.4（`x[:n]` 截断那次）。

## 2. 消融实验（`sandbox/tmp/ablate_stages.mjs`，逐级直接调 `shell.mjs`）

基准：完整 cab 链在 0.5~8 s 的 **20–120 Hz 漂移**。

| 级 | 20–120 漂移 | 相对完整链 |
|---|---|---|
| ① 干源（无壳） | 0.0833 | — |
| ② +smear | 0.1011 | — |
| ③ +propagation | 0.1016 | — |
| ④ +conduct | 0.0939 | — |
| ⑤ +nonstationary | **0.1207** | **+10%** |
| ⑥ +saturate | 0.1124 | — |
| ⑦ +art = 完整链 | 0.1096 | **0%** |
| ⑧ 完整链但 nonstat 参数全 0 | **0.0848** | **−23%** |
| ⑨ saturate.drive 0 | 0.1101 | +0% |
| ⑩ art.warmth 关 | 0.1106 | +1% |
| ⑪ art.room 关 | 0.1114 | +2% |
| ⑫ art.clarity 关 | 0.1096 | +0% |
| ⑬ art 整级关 | 0.1124 | +3% |
| ⑭ 距离/墙 关 | 0.1118 | +2% |
| ⑮ smear 关 | 0.0966 | **−12%** |

**结论**：

1. **底噪层无罪** —— 关掉底噪后 20–120 Hz 的漂移几乎不动（0.1043 vs 0.1003，噪声级）。
2. **控制帧率（50 Hz 分帧）无罪** —— 帧率段只有 0.0007，比漂移段小两个数量级。
3. **`nonstationary`（非平稳调制）是壳子里最大的单一贡献**：它一级就加 +0.027，
   关掉它整链降 **23%**。参数是 cab 预设的
   `amDepth 0.30 / amRateHz 0.9 / beatHz 5.3 / beatDepth 0.15 / textureDepth 0.38`。
4. `smear`（扩散/做旧，18 ms 湿 0.45）是第二个：关掉降 **12%**。
5. 饱和、艺术化（暖化/去刺/清爽/空间）、距离与墙：**全部 ±3% 以内**（噪声级）。
   ⇒ "艺术化加工"不是颗粒感的来源。
6. **干源自己就已经是实录的 5.2 倍**（0.0833 vs 0.0161）—— 全部壳子加起来把 0.0833
   抬到 0.1096，只占三成。

## 3. 没解决的根因（如实记录）

**干源（牵引层）的 20–120 Hz 包络漂移是实录的 5 倍**，这一条没解决。

已排除的解释：
- ❌ 梳齿太稀：带内线数我们 19~21 根、实录 17~21 根，**一样**；
- ❌ 2f₁ 独大：补平 `humFundamentalGain` 0.15→0.5（`motorD` / `kei40`）后
  漂移 0.0772 → 0.0737，**只动 5%**；
- ❌ 我的第 41 轮延伸：`motorB` 0.0880 → `motorC` 0.0772，延伸反而略降；
- ❌ 50 Hz 分帧（见上）；
- ❌ 底噪（见上）。

剩下的可能（**未验证**）：
- 实录本身有**宽带本底噪声**（轮轨/风/环境），它会把任何带内的包络**抹平**；
  我们的合成层在起步段几乎是纯谐波 + 噪声裙，包络自然更"跳"。若是这一条，
  那这不是缺陷，而是**干净合成的固有代价**，要靠底噪/扩散补，而不是改谐波。
- 换档（27 档、变调比 maxStep 1.15）在起步段切换较频，每档的**初始相位**不同 ⇒
  在 20~120 Hz 造成慢起伏。`preview.mjs` 用 `phase` Map 保相位连续，
  但**跨档**（不同文件）之间没有相位对齐 —— 这一条**没有验**。
