## 0. 这一片解决的三件事

1. **作者不能改**：F1 只能"看一眼"，改还是得改 JSON。F2 补上绘制器（拖拽/吸附/图层/撤销/属性面板/条件构造器/保存）。
2. **一块牌只能写死一句话**：真实水牌要"下一站 ⇄ 终点"轮着翻、要闪烁、要滚动。F3 把这些变成**声明式**的（`pages` / `anim`），仍然一行代码都不用写。
3. **键的清单散在三处**：引擎里一个字符串、工作室里一个表单、校验脚本里一份副本 —— "作者写了 `colour`，谁都不吭声"就是这么来的。F3 立了**一份机读键表** `schema.json`，三处都从它读。

## 1. 面文档 v2 的新键（一句话各一条）

| 键 | 一句话 | 为什么不是别的做法 |
|---|---|---|
| `pages` / `pageSeconds` / `pageExpr` | 多页；按时长自动轮，或用表达式指定（数 = 下标、**回绕**；字 = 页名） | 不做"页 0 占位"：没写 `pages` 时顶层 `elements` 就是第 0 页，**v1 文档一个字节都不用改** |
| `anim`（`blink`/`marquee`/`fade`/`spin`） | 逐帧的三个量：画不画、走到哪、多透明 | 不做"每帧重画"：**有动画的文档才在签名里带时间桶**（默认 8 fps），没有动画的牌回到 F0 的"数据不变就不重画" |
| `image`（`src`/`fit`/`alpha`/`tint`） | 资源包里的图贴进一个框 | `tint` 在**加载时**调好并缓存（对像素的乘法不该每帧做） |
| `foreach`（`var`/`of`/`as`/`index`/`limit`/`elements`） | 按列表重复一串元素 | 展开在 `plan()` 里做完 ⇒ **画法完全不知道"重复"这件事**（7 种画法一行都没改重复逻辑） |
| `roll` / `tilt` / `drum` | 整面滚转 / 仰角 / 翻牌机 | 三段都只动**四边形的基向量**，四个角仍然 `中心 + right·a + up·b + normal·lift` 算出来 —— 没有欧拉角，也复用了抬升与绕序那份实现 |
| `fps` | 动画重画节拍（1..30，缺省 8） | 8 fps 的走马灯看起来已经连续，代价是 60 fps 的 1/7 |

## 2. 工作室：从"看得见"到"拖得动"（F2 后半）

F1 只做到"打开一块面、看一眼"。F2 补上**绘制器**，而且刻意选了"编辑**原始 JSON**"这条路：

* **事实来源就是 `faces[name]` 那一段 JSON**：拖拽改的是 JSON 里的 `x`/`y`，不是某个内存里的对象图。
  于是"撤销"就是 JSON 快照栈，"保存"就是把这份 JSON 原样写回文件 —— 中间没有第二份状态可以对不上。
* **属性面板按 `schema.json` 生成**：加一个键（Java 侧改 `MmtrFaceSchema` → 重生成 `schema.json`），
  绘制器里就多一个输入框，**页面代码一行都不用改**。这是"开放性"落在最容易被忽略的那一环（编辑器）。
* **画面 = 引擎的解析器**：预览走的是 `parseDocument` + `painter.mjs`（与引擎共享向量钉着的那两份），
  不在编辑器里复刻一套解析（那是"预览与游戏不一样"的温床）。绘制器因此解析**两份**：
  `state.doc`（编辑视角：只看当前页）与 `state.engineDoc`（引擎视角：整块面含 `pages`）。
* **条件构造器**：行式编辑（字段 ▾ + 算子 ▾ + 值），支持与/或与嵌套组，随时可切源码模式；
  下拉里的字段来自 `fields.json`、算子来自与 Java `operators()` 逐项同序的那份清单；
  判"有值"会给**正确的写法** `{"!!":[{"var":"…"}]}`（而不是踩过的 `{"!=":[…,""]}`）。
* **保存是唯一的写入口**：`POST /save`，白名单（`sandbox` / `mmtr/tools` / `run/resourcepacks`）+ 只写 `.json` +
  覆盖前写 `<文件名>.bak-studio`；白名单外 403、穿越/绝对路径 403、非 POST 405。
* **几何口径按格式文档 §3 的锚点定义**：矩形/图片是**左下角**、圆/圆弧/表盘是圆心、文本是那个点；y 轴朝上。
  吸附到 0/0.5/1 与其它元素的同一条边（阈值 0.01），`Ctrl` 临时关掉吸附，`Shift` 只改一个轴，
  `Alt` 拖 = 复制，方向键 0.005 / `Shift`+方向键 0.001，撤销栈上限 100。

判据（全部实跑）：`designer-selftest.mjs` **43/43**（纯函数层：几何/命中/吸附/微调/路径/构造器，含反例）；
真浏览器 CDP 探针 `sandbox/face-studio/cdp-designer-probe.mjs` **32/32**（派发真鼠标键盘、每步从 DOM 读回、
最后从磁盘核对：拖拽吸附、Alt 复制、Shift 单轴、Ctrl 不吸附、撤销上限、图层置顶、保存 + `.bak-studio`、
页签切页重画）；`POST /save` 的 200/400/403/405 各自复现；无服务器时页面给红字说明而不是白屏。
## 3. 加进来的三块"纯的东西"，和为什么它们是纯的

Java 侧的渲染类（`MmtrFaceElements` / `MmtrPanelCanvas` / `MmtrPanelQuad` / `MmtrFaceRuntime`）**进不了离线用例**（它们 import 游戏类）。所以 F3 把凡是"作者会盯着看、错了看不出来"的口径都抽到 `mmtr.face` 包里：

| 新类 | 装什么 | 判据 |
|---|---|---|
| `MmtrFaceAnim` | 相位/透明度/角度/时间桶 | `MmtrFaceAnimTests`（13 条，含负时钟、`onMs=offMs=0`、`fps` 越界） |
| `MmtrFaceGeometry` | `fitRect`（三种装法）、`marqueeLeft`、`drumAngle`、`prismRadius` | `MmtrFaceGeometryTests`（11 条） |
| `MmtrFaceSchema` | 键表 + 缺省 + 导出 `schema.json` | `MmtrFaceSchemaTests`（7 条，含"画法读的每个键都登记过"） |
| `MmtrFaceDocument.plan()` | 选页 + 展开 `foreach` + 绑定 `as`/`index` | `MmtrFaceDocumentV2Tests`（11 条）+ 共享向量 |

**缺省值只有一处事实**：`Element.number/string/flag` 现在先问键表（`MmtrFaceSchema.defaultNumberOf`），所以"工作室面板上显示的那个 0.44"和"引擎真的用的 0.44"必然是同一个数 —— F3 之前画法里各写一份常量，两边迟早分家。

## 4. 防分家：共享向量从"算子"扩到"文档"

| 向量文件 | 条数 | 谁跑 |
|---|---|---|
| `conformance/logic.json` | 68 | Java `MmtrFaceLogicTests` + 工作室 `selftest.mjs` |
| `conformance/document.json` | 65 | Java `MmtrFaceDocumentVectorTests` + 工作室 `selftest.mjs` |
| `conformance/geometry.json` | 21 | Java `MmtrFaceGeometryTests`（读同一份）+ 工作室 |

`document.json` 的判据面**刻意选在语义层**（哪一页、会画哪些字、展开成哪几条元素、`fps`、翻牌机角度），不比对像素 —— AWT 与 Canvas2D 的字形与抗锯齿永远不可能一样，那样的向量只会天天红。

**这一层马上就抓到了真东西**（两边各自实现，都对不上）：

- `marquee.direction` 只有明确写 `right` 才反向。Java 原来写的是"不是 left 就算 right" ⇒ `"rihgt"`（拼错）会**换个方向**，而工作室是"按缺省向左"。裁决：以严格口径为准，Java 改。
- **显式 `null` 等于"没写这个键"**（`require`/`when`/`pageExpr`/`of`/`needle`）。Java 原来 `require: null` ⇒ 总是可见，工作室原来 ⇒ 静默不画；`when: null` 两边都当成"条件不成立"⇒ 元素消失。三个坑一条规矩收掉：**JSON 里没有"有值但是 null"这种状态**（与"取不到的字段不放进去""空串算没有"同源）。
- 翻牌机的语义：一个周期里**前 `1 - turnFraction` 停在第 k 页**（正面就是 `pageIndex` 那一面），**最后 `turnFraction`** 翻到第 k+1 页，落地那一刻正好是 `pageIndex` 前进的时刻。这里连错两版、两次都是被用例抓住的：第一版"周期开头就翻" ⇒ `pageExpr` 指定页时**整整差一页**（指定页的水牌永远显示下一页），而且比"不用翻牌机的多页"早 1/4 周期换页；第二版把"停稳"实现成 `pageClockFraction = 1`，同一个 off-by-one 又从另一头钻回来。

## 7. 踩坑（都是当场修掉的）
1. **时间取模**：Java 的 `%` 对负数给负余数 ⇒ 时钟走到负数时动画会"跳回去"。用例 `aNegativeClockStillWalksForward` 钉住。
2. **`fade` 写成锯齿波**：三角波在中点最亮、整周期回到最暗；锯齿波会在周期末"啪"地跳回最亮。
3. **翻牌机的 off-by-one 连踩两次**（见 §4 第三条）：第一版"周期开头就翻" ⇒ `pageExpr` 指定页时整整差一页；第二版把"停稳"写成 `pageClockFraction = 1`，同一个错从另一头钻回来。
4. **`prismRadius` 在 `count: 2` 时退化成 0**（`tan(π/2)` → ∞）：两块面共面 = 一块翻来翻去的平板。这是**几何上对的**，但要在文档里写清楚（要厚度就写 `radiusM`）。
5. **走马灯不裁就会压在旁边元素上**：`pushClip/popClip` 是必须的（"跑出牌子"在贴图上的表现不是看不见，而是盖住别人）。
6. **`x2`/`y2` 的缺省不是常数**（= 跟 `x`/`y` 一样）：键表里记 `null`（"跟随"），画法兜底 —— 写成 `0.5` 会让"没写终点的线"从零长变成斜穿整块牌。
7. **`gauge.width` 是 `lineWidth` 的别名**：键表里 `lineWidth` 有缺省值，所以不能靠"外层兜底"，得先看作者到底写了哪个键。
8. **格式文档自己写错了三处**（都是这次对照实现发现的）：算子写了 32 个却把没实现的 `merge`/`reduce`/`log` 列了进去（实际 32 个是另一组，见格式文档 §6.1 的新表）；`gauge` 的 `width`/`lineWidth` 缺省写成一个；`image.src` 漏了命名空间会兜底成 `minecraft:`（文档没写）。
9. **`saf420.json` 不是锚点 JSON**：它是 consist 配置，`faces` 嵌在 `cars[i]` 里。拿它当 `--anchors` 喂校验脚本会得到一份"零个面的空 PASS"（现在脚本会警告了）；工作室的绘制器同样被这条绊了一次（`parseDocument` 只认根上的 `faces`），修法是"先拼一份 `{"faces":{名:那一块面}}` 投影再解析"，并把编辑路径记成 `facesPath`。
10. **`"0"` 这个颜色是哨兵，不是不透明黑**（★ 绘制器抓出来的）：文档与键表都写着"0 = 不铺底 / 用 `textColor` / 全透明"，而 `parseColor("0")` 按十六进制算成 `0xFF000000` —— 写 `"background": 0` 会画一块黑板。现在 `"0"`（含 `#0`/`0x0`/带空白）直接返回 `0`；要黑就写 `#FF000000` 或 `000000`。判据 `MmtrFaceDocumentV2Tests#zeroIsASentinelNotOpaqueBlack` + 共享向量的 `expect.background`。
11. **`ImageIO` 要先写临时缓存文件**（见 §5）：临时目录不可写 ⇒ 图全变洋红占位框。离线工具靠给 java 一个可写的 `java.io.tmpdir` 绕过；**代码里也修了**（`ImageIO.setUseCache(false)`），因为这条坑跟图片、跟资源包毫无关系，作者不可能自己查出来。
12. **绘制器自己的几个坑**（都是自检/探针抓的）：`selection === null` 时渲染图层读 `.kind` 崩掉（第一次截图就是红横幅）；"引擎此刻选哪一页"从**投影后**的文档算 ⇒ 永远 1 页（投影把 `pages` 删了，改成"编辑视角 / 引擎视角两份解析"）；`"pages": []` 要按"没写"处理（引擎存 `null`）；状态栏读的是拖拽前的旧引用（坐标慢一个事件）；撤销栈上限 100 的语义是"最老的被挤掉"（105 步只回得来 100 步）。
13. **两位构建者同时改同一份 JS**：一位把 `fitRect` 重复声明写进了 `painter.mjs`（`Identifier 'fitRect' has already been declared`），模块图挂掉 ⇒ 绘制器整块起不来。这是"零构建、多文件共享目录"的固有风险；规矩是**按文件分片**（一人一份文件），发现别人的文件有问题就报，不要顺手改。

14. **同一条 off-by-one 的第三次现形**（这次是 JS 侧）：`FaceDocument` 上漏了 `pageClockFraction()` 方法，而画法里那句 `typeof … === 'function' ? … : 0` 的**静默兜底**正好让它按 0 算 —— 旧语义下 0 与 1 是同一面，看不出来；新语义下"翻牌机永远停在周期开头"就露出来了。修法两条：补方法，**并把静默兜底改成记一条 problem**（"版本不匹配就用默认值"这种写法在这个仓库里已经攒了好几次教训：它会把你正在查的那个错藏起来）。
15. **窗口末尾那一毫秒**：`t = pageSeconds * 1000` 那一刻 `pageIndex` 已经翻页、`clockFraction` 归 0，所以"窗口末尾"的判据要取 `t = 3999`（`0.99975`）—— 共享向量里写的是四舍五入后的 `0.9998`，于是角度会差万分之几度；Java 侧因此把这个判据的容差定成 **0.05°**（并写清理由：输入被舍入 + `smoothStep` 在两端最陡），远小于"翻错一页"（120°/180°），该抓的都抓得住。

## 9. 欠账（诚实清单）

1. `conformance/geometry.json` 的**两端闭环**：Java 侧读了同一份文件；工作室侧的跑法与条数见 §6 的表（这一条按交付时为准）。
2. **折叠面（facets）仍不支持面文档**（曲面仪表盘那块牌由老渲染器画），运行时跳过并记一次。
3. `foreach` 的数据源目前只能是 `vars` 里的数组字面量 —— 引擎快照还没有列表字段（"停站表"之类），
   补法是走四步曲：字段表 + 同步键 + 提供者 + 向量。
4. 翻牌机在**工作室里只是 2D 示意**（真几何在 `MmtrFaceGeometry`/`MmtrPanelQuad`），作者要看真效果得出图或进游戏。
5. `image` 在离线工具里靠"资源包目录兜底"找图，找不到画洋红占位框（**不报错**是刻意的：一块坏图不该让整块面不画）。
6. 元素几何仍然只接受数字（`x`/`y`/`w`/`h` 不能写表达式）；`anim`/`rotate`/`opacity` 是逐帧量，二者不是一回事。
