# 386 · 无后处理的电气音：怎么把它单独切出来听
用户口径（第 40 轮，两句）：

1. 「生成一个**无后处理的纯电机音**听一下」
2. （我列出模型里的五层之后）「就是**所有电气音**」

所以要的是：**基波簇 + 载波簇 + 固定音族**这三层，
**不含**齿轮层（机械）、**不含**底噪床与壳子（环境 + 路径 + 艺术化）。

---

## 1. 模型里"电机音"到底是哪几层

| 层 | 频率 | 是不是电气 | 在哪生成 |
|---|---|---|---|
| **基波簇** | `n·f₁`，n=1…12，`humLowpassHz 900` 滚降，2f₁ 最强（磁歪） | ✅ 电磁嗡鸣本体 | 烘进循环（`bake.mjs synthesize`） |
| **载波簇** | 同步段 `p·f₁` ± `n·f₁` 边带（`p` 取 `pulseLadder`）+ `2f_c/3f_c` + 转子槽谐波 | ✅ 逆变器电流 | 烘进循环 |
| **固定音族** | 2097 / 3159.5（随 f₁ 下滑）/ 4195 / 6294 / 8392 / 354.5 Hz | ✅ 逆变器电子音 | 播放端独立层（`fixedTonePartials`） |
| 齿轮层 | 16 齿啮合 975 Hz @100 km/h | ❌ 机械 | 独立第二播放器（`manifest.gear`） |
| 底噪床 | 滚动 + 风噪 | ❌ 环境 | 只在 `--shell` 时加 |

⇒ **"所有电气音" = `--gearvol 0 --notone` 的反面**：
`--gearvol 0` 去掉齿轮，**不加** `--shell` 就没有底噪床。
产物：

```
node mmtr/tools/sound-studio/preview.mjs sandbox/sound-studio/baked/kei38 \
  sandbox/sound-studio/baked/preview-kei/motorB.wav --ogg --target 130 --gearvol 0
```

⚠ **不加 `--shell` 就没有壳子、也没有底噪床** —— 底噪床那一段整个包在
`if (shellParams && bedScale > 0)` 里（`preview.mjs` 第 662 行附近），
所以"无后处理"不需要额外交代，不给壳子就是"一个滤波器都没有"。

## 2. 这一轮暴露的两处问题

### 2.1 `--gearvol 0` 生效了，但**日志说它没生效**

`Number.isFinite(0) && 0 >= 0` 为真 ⇒ 增益确实是 0、齿轮确实一个样本都没加
（这一行原来是**对的**，我一开始误判成 `f || 0.5` 那种写法，git diff 可证没改它）。

真正的缺陷在**报告**上：关掉齿轮之后日志仍然打印

```
本趟出声 N 帧，平均变调 1.000（出区间静音，不夹取）
```

`N` 是"速度落在齿轮可用区间内"的帧数，**与增益无关** ——
看去像是齿轮还在播。⇒ "按设计失败/按设计关闭"必须在报告里**显式说出来**，
否则下一次仍然要靠翻代码才知道它到底是关的还是哑的。
现在 `gearVolumeScale === 0` 时打印 `ⓘ --gearvol 0：整层归零`。

### 2.2 命令行解析把**位置参数**当成布尔开关的值

```js
// 错：下一个 token 不以 -- 开头就吃掉
flags.set(argv[i].slice(2), argv[i + 1]?.startsWith('--') ? 'true' : argv[++i]);
```

`--ogg <目录> <输出>` ⇒ 目录被吃成 `ogg` 的值 ⇒ 位置参数整体**左移一位**
⇒ 输出路径变成输入路径 ⇒ ffmpeg 报
`Output ... same as Input #0 - exiting`。

这是最难查的一类错：命令行看着完全正常，报错在 ffmpeg 里。

**修法**：布尔开关走白名单 `BOOL_FLAGS = {ogg, ab, notone}`，永不消费下一个 token
（写 `--ogg true` 也照旧认，兼容老命令行）。
**同类风险**：以后再加布尔开关必须同时加进这个集合，否则同样的坑会以
"输出路径错位"的形式复现。

## 3. 固定音族占多少：**2.5% 能量，但 2~9 kHz 差 12~15 dB**

口径：两条产物**共用同一个归一增益**（`0.89 / max(两条峰值)`），
否则各自峰归一到 0.89 会让"多了固定音族"变成"整体更轻"，对照就听不准。
能量用**绝对带能量**（相对各自总能量），不用带占比（§384 §8.4 的坑）。

起步 0.5~8 s：

| 带 Hz | A 只有基波+载波 | B 全电气 | B−A |
|---|---|---|---|
| 20-50 | −8.4 | −8.6 | −0.1 |
| 50-100 | −4.3 | −4.4 | −0.1 |
| 100-300 | −3.5 | −3.6 | −0.1 |
| 300-630 | −16.1 | −15.7 | +0.3 |
| 630-1000 | −25.6 | −24.1 | +1.5 |
| 1000-2000 | −27.7 | −27.8 | −0.1 |
| **2000-3000** | −32.5 | **−20.1** | **+12.4** |
| **3000-4000** | −35.6 | **−20.9** | **+14.7** |
| 4000-6000 | −36.0 | −29.7 | +6.2 |
| **6000-9000** | −38.7 | **−26.2** | **+12.5** |
| 9000-16000 | −41.8 | −41.8 | +0.1 |

高速 60~80 s（f₁ ≈ 48.5 Hz，已换到 1 分周）：**所有带差 ≤ 0.1 dB** ——
固定音族那时只剩常驻的 354.5 Hz 族（355/709/1063 Hz），
落在 300~2000 里，量不出来。

**起步段 RMS**：A 0.13976 · B 0.14312 · 差（就是固定音族）0.02274
⇒ 按能量占 B 的 **2.5%**。

★ **这就是"2.5% 却听得出来"的正确读法**：
固定音族在**总能量**上是零头，但它独占 2~9 kHz 这**一整片没有别的东西**的区域
（基波簇被 `humLowpassHz 900` 压掉、载波簇在 300 Hz 以下）。
所以它决定的是**明亮度/电子感**，不是响度 —— 与 §384 那种"带占比会骗人"是同一类陷阱的
**反面**：这里是"总量骗人，局部是真的"。

这也解释了为什么 4 kHz 硬砍（第 39 轮）砍掉的**主要就是这一族**：
它是 2~9 kHz 唯一的内容。
