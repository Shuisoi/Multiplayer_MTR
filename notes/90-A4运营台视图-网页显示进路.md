# 90 - A4 运营台视图：网页控制台显示每列车进路

> A4 的最后一块"OP/玩家视图"：此前进路只能从 JSON feed 或 `interlock` 指令看到，
> 现在运营台（`http://<server>:8888/` → 列车任务面板）直接显示。

## 1. 界面

| 位置 | 内容 |
| --- | --- |
| 面板标题下 | `{{mirrorSummary()}}`：`N 条轨被进路锁定 · M 处进路未设（起点信号红）`；无进路时 `无进路：信号按占用链显示` |
| 每列车副行 | 任务标签后追加 `目标 …XXXX`（SET）或 **等待理由**（PENDING，点名道岔与持有人） |
| 每列车徽章 | `进路 列车·已设 6轨` / `进路 调车·待设 6轨`（SET 绿、PENDING 红） |

数据全部来自既有 feed（`mmtr-trains` 的每车 `route` + 顶层 `routeMirror`），**没有**新增服务端接口。

## 2. 改动

| 件 | 内容 |
| --- | --- |
| `mmtr-trains.service.ts` | 新增 `MmtrRouteState` / `MmtrRouteMirror` 类型；`MmtrTrainState.route?`；`routeMirror` 信号并在 poll 中填充 |
| `mmtr-ops-panel.component.ts` | `routeLabel` / `routeDetail` / `mirrorSummary` / `shortHex` |
| `mmtr-ops-panel.component.html` | 镜像摘要行 + 进路徽章 + 副行目标/理由 |

## 3. 构建链（重要，容易踩）

网站资源是**编译期嵌进引擎 jar** 的（`WebserverSetup.setup` → 生成 `WebserverResources.java`）：

1. `cd mmtr/engine/website && npm run build`（含 `ng lint`，本片通过；仅剩既有的 `map.component.scss` 预算告警）；
2. **删掉** `engine/src/main/java/org/mtr/core/generated/WebserverResources.java` 再构建 —— 该任务只声明了输出、
   没声明网站 dist 为输入，Gradle 会判 `UP-TO-DATE` 而**不重新嵌入**；
3. `engine/gradlew.bat shadowJar`（`setupWebserver` 重新生成资源）→ 同步 `game/libs` 的 jar（先停服）→ 重启。

## 4. 验证

  **注意**：esbuild 把非 ASCII 转义为大写 `\uXXXX`，直接搜中文会漏判（本片先踩了一次）。
- 引擎 Java 代码本片未改动（472/0/2 不变量）；`WebserverResources.java` 属 `.gitignore` 的 `generated/`，入库只有 TS/HTML。
