# 50 - 左右门分控：Y 开左门 / U 开右门（HUD 显示 DO 但门不动）

> 用户实机反馈（钥匙归属修好、进得了驾驶室之后）：坐在驾驶位按 G，HUD 显示 `DO`，但车上的门
> 没有动作。用户判断"可能需要识别站台"，并给出方案：**直接按 Y 开左门、U 开右门**。

## 根因（用户的判断正确）

MTR 的门渲染有一道**站台邻近检查**：`RenderVehicles` 只有在门洞旁找到站台方块（或已解锁的
PSD/APG）时才把该门洞放进 `openDoorways`，而门扇是否滑动又取决于它是否属于 `openDoorways`：

```java
final boolean canOpenDoors = RenderVehicleHelper.canOpenDoors(doorway, carTransform, doorValue); // 找站台方块
if ((doorBlockedAmount[0] > 0 || vehicle.persistentVehicleData.checkCanOpenDoors()) && canOpenDoors) { openDoorways.add(...); }
...
final double doorValue = canOpen ? vehicle.persistentVehicleData.getDoorValue() : 0;   // 门扇位移
```

引擎侧 `doorTarget` 已经翻成 true（所以 HUD 是 `DO`），客户端 `doorValue` 也在爬，但**门洞没进列表**，
于是门扇的 `canOpen` 恒为 false、位移恒为 0。列车停在侧线（本项目出库/调车的位置）时必然如此。

另外 MTR 只有"整车一个门目标"，没有左右之分；现实里司机只开靠站台那一侧。

## 修复：引擎按侧保存，客户端按侧渲染

**引擎**（`vehicleExtraData.json` 新增三个随车同步字段）：

| 字段 | 含义 |
| --- | --- |
| `mmtrDoorLeft` / `mmtrDoorRight` | 两侧各自的目标状态 |
| `mmtrDoorManual` | 本次开门/关门是**人工**下达的（司机门键），客户端必须按旗标执行、跳过站台规则 |

`VehicleExtraData`：

- `openDoors()/closeDoors()`（引擎自动开门：到点开门、动车关门）→ 两侧一起置位/清零，`mmtrDoorManual = false`；
- `mmtrSetDoors(action, side)`（船员/指令）：只改指定侧，`mmtrDoorManual = true`，聚合 `doorTarget = left || right`
  （MTR 的乘客逻辑与 HUD 仍读聚合值）；
- `checkForUpdate()` 把三个旗标纳入变更检测——只关一侧时 `doorTarget` 不变，否则客户端收不到更新。

**客户端**：

- `MmtrDoorSides`（新）：把"左"落到车体坐标——车模沿 Z 展开、+Z 朝编组尾部，A 端司机面向 -Z，
  左手为 **-X**；B 端司机面向 +Z，左手为 **+X**。据此判断门扇/门洞属于哪一侧。
- `ModelPropertiesPart.renderNormal`：人工状态下门扇的 `canOpen` 改由**所在侧**的旗标决定，
  不再看 `openDoorways` 是否含该门洞。
- `RenderVehicles`：人工状态下直接由旗标构造门洞列表，并按开启侧把门洞盒**裁剪**到该半车宽
  （资源包的门洞盒常常是整幅车宽，左右门扇共用同一个盒子），所以非站台处也能从开的那一侧上下车。
- `KeyBindings`：`MMTR_DOOR_LEFT` 默认 **Y**、`MMTR_DOOR_RIGHT` 默认 **U**（设置里可改）。
- `VehicleRidingMovement`：只有**在岗司机**（`mmtrCabDriver`）按 Y/U 才发指令
  （`PacketMmtrCabOp.DOORS` 的 `cab` 字段携带 `left`/`right`）。
- HUD（`MmtrCabHudRenderer`）：人工状态下在 `DO/DC` 后面补 `L`/`R` 两个灯，一眼看出哪侧开着。

**指令**：`doors <id> [open|close|toggle] [left|right|both]`（网页 OP 与游戏内共用），
结果回显 `L=… R=… 手动=…`。

## 验证

- 引擎全量 **398/0/2**（394 → +4：`MmtrDoorSideControlTests` 两侧独立、整侧命令、引擎自动门不置人工标记、side 解析容错）；
- 引擎 shadowJar 已重建并同步（13:03）；`:fabric:compileJava` 通过；
- **两个进程都要重启**。

实机确认：

1. 进驾驶室后按 Y → 左侧门扇滑开、右侧不动，HUD 出现 `L` 灯；再按 Y 关左门；
2. 按 U → 右侧门扇滑开，`R` 灯亮；
3. 站台旁（非司机门）按 G → 两侧一起开（人工、双侧）；
4. 侧线里开门后从开的那一侧可以走上/走下车；
5. 列车一动 → 门自动关，`L`/`R` 灯同时灭。
