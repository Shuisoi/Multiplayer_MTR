## 一、总表（46 个可用块）

「导出」列的含义：
- **✅ 标准** = `CopycatModelNeoForge$Renderer`（标准 BakedModel 路径）→ MineToMesh 的 `RendererReplay` 抓取最干净
- **⚠️ 动能** = `KineticCopycatRenderer` + `CopycatInstance`（**Flywheel 实例化路径**）→ 交给 `FlywheelBackendAdapter`，是导出最可能出问题的一类

## 二、按"车体部位"选块的速查

| 要做的东西 | 首选块 |
|---|---|
| 主体填块 | `copycat_block` |
| **车头曲面 / 流线** | `copycat_slope` + `copycat_vertical_slope` + `copycat_corner_slice` |
| 车体厚度微调 | `copycat_layer` / `copycat_half_layer`（比半砖更细） |
| 侧墙薄板 | `copycat_panel` / `copycat_half_panel` |
| 车窗 | `copycat_pane` / `copycat_flat_pane` |
| 底架梁 / 车顶横梁 | `copycat_beam` |
| 极小细节（铆钉、把手） | `copycat_byte` / `copycat_byte_panel` |
| 门 | `copycat_door`（+ `copycat_trapdoor` 做检修口） |
| 护栏 | `copycat_fence` / `copycat_wall` / `copycat_bars`(create) |
| 纯视觉、不想挡路 | `copycat_ghost_block` |
| 车顶阶梯 / 裙板 | `copycat_stairs` / `copycat_vertical_stairs` / `copycat_step`(create) |

## 三、操作要点

- **贴材质**：手里拿着目标方块 **右键** 伪装块 → 套上那个方块的外观
- **循环朝向/通电态**：**再次右键**
- **重置材质**：**扳手右键**
- **可用材质白名单**：靠数据包标签 `create:copycat_allow` / `create:copycat_deny` 控制
- 材质是**方块实体状态（客户端组件）**，1.21.1 下**手里必须有那个方块**才能贴

---

## 四、导出时的注意

1. **优先用 ✅ 标准 那批**，动能列（⚠️）不要用于导出
2. **Flywheel 有距离剔除**（`flywheel-client.toml` → `limitUpdates = true`）。整车拼好后相机要拉够远，否则远处 copycat 可能没渲染 → 导出缺失
3. 怀疑漏块时看 `minetomesh-exports/<名字>/` 里的**导出报告**（MineToMesh 自带 `ExportReport` / `Diagnostic`），比在 Blender 里瞪眼睛找快
4. 若某类块导出后是空的，换 `flywheel-client.toml` 的 `backend`（`DEFAULT` → `FLYWHEEL` / `INSTANCING`）再试
