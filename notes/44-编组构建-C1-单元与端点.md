# 44 - 编组构建立项与 C1：连挂单元与连挂端点

> 用户口径（2026-09-09）：连解挂的粒度是 **Unit（连挂单元）**，不是车厢。动车组 8 节 = 1 个 Unit
> （内部永不连解挂，两端各一 Coupler → 支持 **8+8 重联**）；机车 1 节 = 1 个 Unit；
> 无动力挂车"**逻辑独立、物理合并**"（车底清单 8 个条目 → 引擎一条 8 节车列，节间 7 个接缝）。
> 连挂后的运动表示**照 MTR 自身实现**；非动力车要在物理层落地。
> 设计：`docs/01-设计/编组构建-连挂单元与连挂端点-设计.md`（C1–C7 分片 + 不变量 U1–U8）。

## 三处关键修正（用户实机/概念）

1. **连解挂粒度是 Unit，不是车厢**：`notes/06` 的"编组 = 单 Vehicle 的车厢序列"只表达了一层，
   会把 EMU 的 8 节从中间切开。→ 新增 Unit/Coupler 两级。
2. **MTR 每股道只允许一辆停场车是信号原因**（用户指出）：现实中连挂同样要**信号允许越过红灯**
   —— 即**副显示**（调车/呼唤显示）。→ C3 不是"开停放窗口"，而是**实现调车授权**：
   S1 加"许可式占用"例外 + **S3 在副显示下不触发 AWS warning** + S4 授权期内不判 SPAD。
   现实基准补进 `参考-英铁AWS与TPWS机制.md` §7；权威标准 **GERT8075 为收费标准**且本机外网不可达，
   故实现为**可配置表**（`aspect → {抑制 AWS, 施加 TPWS 等效保护, 限速}`）并标 `UNVERIFIED`。
3. **MTR 自身就是"多节 + 多转向架"的现实列车模型**：单 `railProgress` + 每节车自带
   `bogie1/bogie2Position` + 客户端 `PositionAndRotation` 用两转向架中点/连线摆位（过弯折角）。
   → 连挂合并为**同一个 Vehicle** 即符合现实表现，**不做多体耦合**，转向架/折角/贯通道零改动。

## C1 已交付（纯数据，零行为改动）

`engine/src/main/java/org/mtr/core/mmtr/consist/`：

- **`MmtrUnitCar`**（record）：车厢（`vehicleId`/`lengthM`/`couplingPadding1,2M`/`powered`/`consistTypeId`）。
  长度用 MTR 约定（`VehicleCar.getTotalLength`：首尾外端 padding 不计）。
  刻意**不复用 `job.MmtrCarSpec`**：依赖方向固定为 **job → consist**，核心不反向依赖 Web 编排 DTO。
- **`MmtrCoupler`**：连挂端点。**身份 = `(unitId, end)`**；携带 `type`（`POWERED_CONSIST` 重联 /
  `HAULED` 牵引）与 `airCharged`。**连接状态不存储** —— 由编组链序派生。
- **`MmtrUnit`**：`UnitClass`（EMU/LOCO/WAGON）+ 车列 + 两端 Coupler；`hasPoweredCar/lengthM/carLengthsM`。
- **`MmtrFormation`**：Unit 链 + 接缝 API（`seamCount`/`seamHeadCoupler`/`seamTailCoupler`/
  `carIndexAfterSeam`/`seamArcM`/`seamPaddingM`）+ `couple`/`splitAfterSeam`（均返回新实例）+
  派生 `cars()/carLengthsM()/lengthM()` + `isCouplerFree`。
- **`MmtrFormationTests` 10 例**：EMU 无内缝不可切；挂车 8 Unit / 7 接缝；**每个挂车接缝可切且切→并往返
  逐项相等（U2）**；`couplingAddsTheSeamPadding`（U2 长度公式）；**8+8 重联 = 16 节 1 接缝**；
  接缝弧长；端点自由/已连（U3）；越界与非法输入拒绝；端点身份只由 `(unitId,end)` 决定。

验证：`:engine:test` 全量 **377/0/2**（起点 367/0/2 → +10，**零新增失败**）。

## 结构性保证（不靠运行时检查）

- **U1 / U6**：Unit 内部**没有 Coupler 对象** → 结构上不存在可切位置（EMU 8 节天然不可分）。
- **U3**：连接状态 = 链序派生（自由端只有首 Unit 的 A 与尾 Unit 的 B）→ 一个 Coupler 不可能有两个对端。
- **U2**：`couple(a,b).lengthM() == a.lengthM() + b.lengthM() + couplingPaddingM(a,b)`，测试逐项断言。
