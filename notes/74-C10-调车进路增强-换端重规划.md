# 74 - C10 调车进路增强（一）：进路规划失败时先换端重规划

> 实机（2026-09-09 19:28）：作业单 `loco` 在 aassdd 车场把机车放好、授了调车权、mission 开始自 arm，结果
> `target rail …FFFF24…83-…24…3E is not reachable from the vehicle` —— 进路直接失败。

## 根因（第一层）

机车是车场式停放（`mmtrConsistWalkerFromYard` + A 端驾驶室），**车头朝向自己股道的尽头**，而它要去的股道
在身后。规划器只做"朝前"的图搜索（BFS 从 `aheadNode` 出发，且不允许回到来路），朝向反了自然一无所获。

真实司机遇到这种情况就是**换端**（双端机车），所以引擎也应该这样做。

## 实现

`Vehicle.mmtrMotionSelfArmMission`：

```java
final MmtrRunPlanner.Plan plan = MmtrRunPlanner.planToRail(simulator, this, targetRail.getHexId(), 1.0);
if (!plan.feasible && speed <= 1e-9 && !mmtrMissionFlippedForTarget
    && mmtrMotionWalker instanceof final MmtrConsistWalker consistWalker && consistWalker.changeEnds(true)) {
    mmtrMissionFlippedForTarget = true;   // 每个 mission 只换一次，避免 A/B 来回翻
    refreshMmtrMotionLegs();
    return;                                // 下一 tick 用新朝向重新自 arm
}
if (!plan.feasible) { mission.fail(plan.reason); return; }
```

- 只在该车**停稳**时换端（`changeEnds(true)` 本身也要求停稳）；
- `mmtrMissionFlippedForTarget` 在 `setMmtrMission` 里复位，保证"每个任务最多换一次"；
- 第二次仍不可达就照常把原因报给任务所有者（不再闷头重试）。

日志：`[MMTR-MSG] motion mission could not be planned facing this way (…) - changed ends on <rail> and retrying`。

## 实机验证

19:28:42 触发成功：

```
[MMTR-MSG] motion mission could not be planned facing this way (target rail … is not reachable from the vehicle)
           - changed ends on FFFFFFFFFFFFFF2C-…-FFFFFFFFFFFFFF83-…-FFFFFFFFFFFFFF3D and retrying
```

换端后仍然 `not reachable` —— 说明**这个车场还需要第二层能力**：中途中折返。

## 第二层：为什么 aassdd 还需要"牵出再推进"

实机拓扑（`mmtr-topology`）：

| 轨 | 端点 | 说明 |
| --- | --- | --- |
| 旧 HST8 道 | (-212,-125) → (-212,61) | 只有南端出岔的尽头式股道 |
| 新长道 | (-220,-125) → (-220,62) | 同样只有南端出岔 |
| 联络 | (-212,-125) → (-212,-159) | 旧道向南的引线 |
| 斜线 | (-220,-125) → (-212,-159) | 新道的唯一入口 |
| 南节点 | (-212,-159) 度 3 | 旧道引线 + 斜线 + 继续向南 (-212,-178) |

从旧道南下到 (-212,-159) 时车头朝南，而斜线要从该节点**向北西**出去——必须**折返**：先继续南下到
(-212,-178) 牵出（pull out），换端/反向，再向北推进（set back）转入斜线进新道。这就是真实调车的
"牵出—推进"，规划器目前只支持"尽头换向"这一种折返。

## 下一步（C10 二）

`MmtrRunPlanner` 需要状态为 (节点, 朝向) 的搜索：允许在某个节点插入一次反向（换端或尾向行驶），
两段进路各自算道岔操作与停车里程；`Plan` 增加 `setbackRailHex`/`setbackCumulativeM`（与既有
`flipRailHex` 同构，但折返点不必是尽头）。做完后 aassdd 的新长道才能被作业单自动走通。
