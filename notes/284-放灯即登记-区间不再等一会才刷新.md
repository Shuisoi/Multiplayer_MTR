# 284 · 放灯即登记：区间不再"等一会"才刷新

> 用户反馈（2026-09-25 实机）：「轨道显示的区间不会立马刷新，而是需要等一会才刷新」。
> 根因**不在**新的区间叠加层，而在**信号灯登记表**：放灯没有事件钩子，新放的灯要等"轮转扫描"
> （一分钟一圈）才进引擎 —— 而区间是从灯切出来的。现象、根因、修法都有日志实证。

---

## 1. 现象与证据（服务端日志，同一段三分钟）

```
[14:16:27] [MMTR-SIG] 自动刷新：灯被敲掉，删除登记 -2,64,-179      ← 敲掉 = 立刻（有事件钩子）
[14:16:55] [MMTR-SIG] 自动刷新：轮转核对 新增 1 盏 [-2,64,-179]    ← 重新放上同一盏：28 秒后才登记
[14:17:50] [MMTR-SIG] 自动刷新：轮转核对 新增 2 盏 [-25,63,-74, -29,63,-74]
[14:18:25] [MMTR-SIG] 自动刷新：灯被敲掉，删除登记 -29,63,-74
[14:18:50] [MMTR-SIG] 自动刷新：轮转核对 新增 1 盏 [-29,63,-74]    ← 25 秒
```

区间**只由灯产生边界**（notes/156/166）。灯不在登记表里 ⇒ 那段区间照旧 ⇒ 轨面上的区间带照旧。
最慢不是 28 秒，而是 `MmtrSignalSync.SWEEP_TARGET_SECONDS = 60`（一轮扫完全部已加载区块）。

为什么只有"放灯"滞后：`MmtrSignalSync` 原来三条路各管一段，而

| 原路径 | 对"放灯"是否管用 |
| --- | --- |
| 区块加载 `CHUNK_LOAD` | ✗ 灯所在区块**早就加载好了**，不会触发 |
| 敲灯 `PlayerBlockBreakEvents.AFTER` | ✗ 只删不增 |
| 常态轮转（≤60 s 一圈） | ✓ 但慢 —— notes/172 当时就写明"**放灯没有对应的事件钩子**" |

## 2. 修法：方块自己的 `onPlaced`

mapping 层其实**给得出**这个钩子（`BlockAbstractMapping.onPlaced2` / `onBlockAdded2`），只是没有方块覆写它。

| 文件 | 改动 |
| --- | --- |
| `block/BlockSignalBase` | 覆写 `onPlaced2`：`!world.isClient()` 时调 `MmtrSignalSync.onSignalPlaced(ServerWorld.cast(world), pos)` —— 与 `onBreak2` 里"删登记"那条路**对称**（敲掉是立刻的，放上现在也是） |
| `mmtr/MmtrSignalSync` | 新增 `onSignalPlaced(...)`：只核对**这一盏**（读方块状态的朝向 + 灯位数，走与区块核对**同一个入口** `Simulator.mmtrSignalRefresh`：只改世界告诉我们的两个值、不动人工绑定、只在新增时落盘），并打一行 `[MMTR-SIG] 放灯即登记 x,y,z` |

轮转**保留**：别的模组放灯、结构生成、`/setblock` 这些没有 `onPlaced` 的路径仍由它兜底收敛。
`onSignalPlaced` 刻意**只登记放置的那一格**（不学敲灯那条按 y-1..y+2 试）—— 避免与扫描口径分叉而生成重复条目；
真出现"登记位置与扫描位置不一致"时由轮转收敛，那时再谈要不要放宽。

## 3. 顺带核实的两件事（都不是缺陷，别再改）

1. **铺轨不滞后**：`ItemRailModifier` 走 `PacketUpdateData.sendDirectlyToServerRail(...)`，而
   `PacketUpdateData.responseType() = ALL` ⇒ 服务端把新轨**广播给所有客户端（含建造者）**，客户端当场有那根轨。
   notes/126 那条"看不见新轨"说的是**外部**（引擎指令）建的轨，与实机铺轨不是一回事。
2. **H 键仍在**：`MmtrDataResync`（notes/126）留着 —— 给"外部建轨 / 确实没跟上"一个立刻重拉的入口。

## 5. 还没做

- 网页控制台那条路不受影响（它每次都现算 `sectionViews()`）。
- 若实机再遇到"区间不动"，先看日志里**有没有** `放灯即登记`：
  - 有 → 问题在别处（那就接着查镜像是哪一段没跟上）；
  - 没有 → 放灯走的不是 `onPlaced`（例如指令/结构放的），轮到轮转管，属预期。
