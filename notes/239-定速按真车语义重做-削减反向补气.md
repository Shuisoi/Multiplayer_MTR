# 239 · 定速（AFB）按真车语义重做：削减 / 反向 / 补气，与气制动手柄耦合

日期：2026-09-23 · 现场第二轮反馈：「不对，还是和现实 AFB 行为不同」→ 追问后用户给出口径：

> **按牵引力来看，AFB 和动力手柄两个相互制约，动力手柄决定当前输出的力，AFB 根据速度来削减或反向电磁制动或应用气制动。**
> **可以自动补气制动，但要和气制动手柄耦合而非合并操作。**

这一条**取代**了 notes/238 里"手柄当牵引上限、只调增益门限"的口径，也取代了
`docs/01-设计/驾驶输入与控制模型.md` §2 早先写的"AFB 不使用气制动 / 司机一碰气制动就退场"。

---

## 1. 现在的调节律（`ThreeHandleDriveController`）

```
speedError = clampCruise(定速)/3.6 − v
牵引联锁：气制动手柄离开"运行"位 ∨ 缸压 > 1% 常用制动力 ⇒ 牵引 = 0
AFB 在岗 = 定速 > 0（司机拉气制动也不退场，靠联锁让路）

speedError > 门限          ① 削减：牵引 = 手柄牵引比例 × clamp(afbGainPerMps × speedError, 0, 1)
speedError < −门限         ② 反向：
                              要的减速度 a = afbBrakeDecelPerMps × |speedError|
                              a×惯性质量 = 需要制动力；电阻制动出 min(需要, 可用×低速衰减)
                              缺口 (需要 − 电阻可用) 折成缸压比例 → **AFB 补气**
|speedError| ≤ 门限        ③ 带内惰行
缸压目标 = **max(气制动手柄诉求, AFB 补气诉求)**   ← "耦合而非合并"：谁要得多听谁的
```

三条要点：

- **动力手柄决定"要的力"**：手动档位就是那份牵引力/电阻制动力；AFB 不改写它，只在它之上做乘性削减。
- **AFB 会补气**（"Fahr- **und Brems**steuerung"）：这正是上一轮和真车最大的差别 —— 原来 AFB 只动电阻制动，
  而电阻制动只有牵引力的三分之一、低速还会衰减，于是"降速/下坡保不住"。现在缺口由气制动补足。
- **补气与 H3 手柄取大耦合**：司机拉 6 档、AFB 只要 1A ⇒ 缸压 0.56（听司机的）；司机只拉 1A、AFB 要更多
  ⇒ 缸压被抬上去。AFB 永远不会把司机的手柄压低，也不会把它吞掉。

## 2. 测试量出来的行为（世界里那台 BR101 的参数）

```
[AFB]  从 0 起步、定速 100、手柄 97：120 s 后 99.25 km/h，峰值 99.25（不超调）
[AFB3] 从 120 km/h 起、定速 100：60 s 后 99.25 km/h，最低 99.25（不下冲）
[AFB4] 从 60 km/h 起、定速 20：最大缸压 1.000（补气真的上了），90 s 后 19.82 km/h
[AFB2] 建满缸压后回"运行"：松闸时 49.90 → 5 s 后 48.65（那几秒在减速）→ 30 s 后 99.00
```

用例（`ThreeHandleDriveTests`，纯 JVM）：

| 用例 | 钉住什么 |
| --- | --- |
| `afbHoldsTheSetSpeedUnderTheWorldTuning` | 保速不超调（峰值 ≤ 设定 +0.5 km/h） |
| `afbBringsAnOverspeedBackDownToTheSetSpeed` | 高出一段能收回来，且不下冲过头 |
| `afbAddsPneumaticBrakeWhenTheElectricBrakeCannotHold` | **补气**：60 → 定速 20 时缸压满、最终稳在 20±2 |
| `afbPneumaticAssistIsCoupledWithTheBrakeHandle` | **耦合取大**：司机要得多时不被压低；司机要得少时被抬上去 |
| `releasingTheBrakeDoesNotHandBackFullTraction` | 牵引联锁：缸压 >1% 期间牵引恒 0、且在减速（修前 5 s 冲 +22.5 km/h） |
| `pneumaticBrakeBlocksTractionWhileAfbStaysCoupled`（改自 `pneumaticBrakeSuspendsAfb`） | 拉气制动不再让 AFB"退场"，只是压住牵引 |

## 5. 遗留

**机辆列车的拖车质量还没进物理**（notes/238 §7 同一件事）：三手柄/有级/无级三个控制器都只用
`type.getPhysics()`（说话那节车自己的质量），`MmtrComposition`（按车求和力 ÷ 总惯性）只在 `AIR_BRAKE` 那一路用。
于是 BR101 + 2×p1 按 82 t 算（真实 162 t）：起步与制动都比真车灵一倍左右，AFB 的补气量也按 82 t 折算。
