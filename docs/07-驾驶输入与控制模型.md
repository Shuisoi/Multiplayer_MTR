# 07 驾驶输入与列车控制模型（M1 规格 v1）

> 范围：MMTR 列车操控重做的“输入侧”语义与“引擎侧”控制接口；本期只落规格与引擎层可插拔控制器 + JUnit，
> 键盘/HID 的实际键位绑定与 HUD 渲染在接入期（M4/M1-接线段）实现，但语义以本文为准。

## 1. 车底与物理参数：服务端 JSON

- 车底（ConsistType）与动力/制动参数由**服务端 JSON** 提供（引擎权威侧加载），不写入世界存档。
- 文件：`<mmtr-config>/consist-types.json`（engine standalone 用 `-r/--config-dir` 或 `--consist-types` 参数指定；MC 内嵌期由 MMTR mod 服务端配置目录提供——接线段实现）。
- 样例：`mmtr/config-example/consist-types.json`（仓库内）。

## 2. 统一输入状态 ControlState（引擎侧，双输入路线合并后）

键盘与 HID 不互斥、可同时操作。上报到引擎的最终“控制意图”归一为：

| 字段 | 含义 |
| --- | --- |
| throttleNotch | 节流阀档位（有级：0..powerNotches；无级模式忽略档位） |
| brakeNotch | 制动档位（有级/降保升：0..brakeNotches；0=缓解） |
| reverser | 换向器档位（-1..1：后退/中立/前进，或按车底 0..N） |
| throttleAxis | HID Y 轴归一 [-1..1]（>0 向牵引方向推；仅变化时上报） |
| brakeAxis | HID Z 轴归一 [-1..1]（>0 施加制动；仅变化时上报） |
| emergency | 紧急制动触发 |
| sourceMask | 位标记：KB(键盘)/HID，用于调试与去抖 |

合并规则（约定，接线段细化）：
- 有级控制型：取 notch 输入；若同时存在 HID 轴变化且模式支持无级，则以轴值换算为目标值。
- 档位命令是“相对/绝对”按模式区分：键盘为相对增减（±1/次），HID 为绝对位置（变化即上报绝对值）。

## 3. 玩家操作路线 A：键盘（默认布局，可在设置改）

| 键 | 动作 |
| --- | --- |
| ↑ | 节流阀 +1 档 |
| ↓ | 节流阀 -1 档 |
| ; | 制动 +1 档（施加） |
| ' | 制动 -1 档（缓解） |
| ← | 换向器 +1 档 |
| → | 换向器 -1 档 |

越级保护：档位不允许跳变（每次只 ±1，控制器内部再做平滑）；松手不回中（保留档位，符合列车驾驶习惯），需要“回零”用持续按 ↓/; 减到 0（接线段另配一键缓解/惰行可选）。

## 4. 玩家操作路线 B：HID（手柄/摇杆）

| 输入 | 动作 |
| --- | --- |
| Y 轴 | 油门（连续值） |
| Z 轴 | 刹车（连续值） |
| 按键 6 | 换向器 +1 档 |
| 按键 7 | 换向器 -1 档 |

- **仅输入变化时上报**（变化阈值 + 死区 + 去抖；不变不发送，避免 20Hz 空转流量）。原始轮询频率不限，但只在变化后产生消息。
- 轴值死区建议 ~0.05；上报最小变化步进可配置（默认 0.01）。

## 5. 引擎侧 DriveController（本期实现 + JUnit）

- 接口输入：`ControlState + ConsistType + 当前速度(含方向) + dt`；
- 输出：目标加速度/目标速度、制动灯状态等（`DriveOutput`）；
- 实现：
  - DefaultDriveController —— 与现 TSC 行为一致（保底，验证“默认行为不变”）；
  - NotchedDriveController —— 有级：档位→牵引力/电制动力曲线（按 ConsistType.tractionCurve）；
  - SteplessDriveController —— 无级：目标牵引力/恒速 + 加速限制；
  - AirBrakeController —— 降保升：列车管/制动缸状态机（缓解-保压-制动-紧急）+ 建压/缓解速率；
- 全部无头 JUnit（纯 JVM，不启动 MC）。
