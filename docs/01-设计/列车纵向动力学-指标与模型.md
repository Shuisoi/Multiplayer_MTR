## 1. 质量与回转惯性（Mass & Inertia）

| 指标 | 含义与模型 |
| --- | --- |
| 静态整备质量 `m`、轴重 `P_i` | 单轴静载荷决定法向正压力 `N_i = P_i · g` |
| 轴重转移系数 | 加减速时构架俯仰使各轴载荷重分配（起动时首轴轻、尾轴重），直接改变起步最大抓地极限 |
| 回转质量折算系数 `ρ`（γ） | 轮对/牵引电机转子/齿轮箱的自转惯量 `I` 折算为平动质量：`m_equiv = m (1 + ρ)`；机车驱动轴 `ρ ≈ 0.15…0.25`，无动力挂车轴 `ρ ≈ 0.04…0.08` |

## 2. 动力与牵引特性（Traction & Powertrain）

动力系统**不能只输出恒定力**，须按电/液力传动特性给 `F_e – v` 曲线（**三段式**）：

| 区段 | 速度区间 | 约束 | 牵引力 |
| --- | --- | --- | --- |
| 恒转矩 / 起动区 | `0 ≤ v ≤ v_base` | 黏着极限 + 逆变器电流 | `F_e = F_max` |
| 恒功率区 | `v_base < v ≤ v_max1` | 主变压器 / 柴油机功率 | `F_e = P_rated / v` |
| 自然特性 / 弱磁升速区 | `v > v_max1` | 弱磁 | `F_e ∝ 1/v²` |

**驱动延迟（一阶惯性滤波）**：操纵杆位 → 轮周转矩之间有滞后，电气传动 `τ ≈ 50…150 ms`，柴油机提速升转速可达数秒。

**牵引力增速控制（斜率限制，用户口径 2026-09-25）**：牵引力的变化率有上限 —— **上升与下降都是
`30 kN/s`**（每秒只能变化 30 kN），用于**减少牵引期间快速加力引发的冲力**。

- 限的是**力**（N/s），不是手柄比例：恒功率段同一个比例的力小得多，按比例限速会跑出完全不同的斜率
  （BR101 在 200 km/h 满手柄只有 115 kN）；
- **方向不豁免**：回杆、AFB 削力、气制动联锁、紧急制动都按同一斜率回落；回落期间的**残余牵引真的在推车**，
  所以纵向合力必须把它与制动力、运行阻力同号相加（不能按分支丢掉）；
- 落地：`ThreeHandleSpec.tractionRampNPerSecond`（缺省 `30000`，`0` = 不限速/旧口径），
  状态量是控制器里"当前真正施加的轮周牵引力"，见 notes/265 与
  `docs/01-设计/驾驶输入与控制模型.md` §3。

## 3. 列车运行阻力（Resistance）

- **基本阻力（Davis）**：`W_0 = A + B·v + C·v²`
  - `A` 机械滚阻（轴承/轨面滚动，与静重成正比）
  - `B` 冲击振动阻力（轮缘侧磨碰撞、悬挂阻尼，线性于速度）
  - `C` 空气动力学阻力（压差 + 侧壁摩擦；头车看迎风截面，中间车看侧壁粗糙度与列车总长）
- **坡道阻力**：`W_i = m g sinθ ≈ m g · i`（`i` = 千分坡度 ‰）
- **曲线阻力**：`W_r = m g · k / R`（标准轨 `k ≈ 600…700`）
- **隧道附加阻力**：活塞效应使 `C` 阶跃放大（通常 ×1.5…3）

## 4. 轮轨接触与黏着（Wheel-Rail Contact & Adhesion）

真实驾驶手感（空转、打滑拉风门）的核心在蠕滑与黏着力：

- **蠕滑率 / 滑差率**：`s = (ω r − v) / max(|v|, |ω r|, ε)`（`ω` 轮对角速度、`r` 滚动半径、`v` 车轴平动速度）
- **黏着特性 `μ–s` 曲线**（简化 Polach / Burckhardt）：
  - 微滑弹性区 `s < s_crit`：`μ` 随 `s` 线性上升
  - 黏着峰值点 `s = s_crit`：最大牵引力，`s ≈ 1%…3%`
  - 宏观打滑区 `s > s_crit`：负斜率衰减 → 暴烈空转 / 抱死擦伤
- **轨道环境 `μ_max`**：干燥干净 0.33…0.38；湿轨 0.15…0.25；湿落叶/油污/黑冰 ≤ 0.08
- **防空转（WSP / Anti-slip）**：`ω̇ > α_threshold` 时减转矩脉冲；**撒砂**增粘 ×1.2…1.4

## 5. 制动系统物理（Braking）

- **列车管风压传递速度** `v_pipe ≈ 250…300 m/s`：长编组（如 50 节货车）尾部制动力滞后首车数秒
- **充排气动态延迟**：制动缸升压按渐进指数建模，常用制动升压约 `3…6 s`（长编组更慢）
- **闸瓦摩擦系数随速衰减（Fading）**：高速时摩擦系数显著下降（高磷铁闸瓦尤甚），低速停车前制动力骤增 → 司机需停稳前减压（缓解冲动）
- **动力制动（电阻/电制动）独立建模**：低速无法自励励磁（通常 `5…10 km/h` 以下切除）；中高速受制动电阻/回馈容量限制

### 5.1 已落地的口径（2026-09-25，notes/266）

| 项 | 口径 |
| --- | --- |
| 列车管 | 定压（标称）**5.0 bar**、运行位充风稳定 **5.2 bar**、初制动(1A) **4.6**、逐级降到 8 档 **3.5**、EB 快排 **3.0** bar |
| 分配阀 | `缸压 = clamp(2.5333 × (5.2 − 管压 − 0.2 灵敏限), 0, 3.8 bar)`；EB 缸压 4.2 bar；**缸簧 0.30 bar 以下活塞不动作** |
| 充排气 | 管：充 0.35 / 排 0.85 bar/s；缸：建 1.30 / 缓 0.95 bar/s（实测 8 档建压 3.1 s、松闸到牵引联锁放开 3.9 s） |
| 缸压 → 力 | `F = F_锚 · max(0, P_bc − 0.3)/(3.8 − 0.3) · κ(v)`；**模块一的活塞面积/杠杆比/盘径比/闸片数折进 `F_锚`**（逐步代出 211 kN 与铭牌 150 kN 差 1.4 倍，口径未对齐 ⇒ 只作新车初值与对账） |
| 力的锚 | **UIC 制动重率**：`a = 0.0065λ + 0.12`、`F = m_equiv·a`，`λ = 制动重量/车底质量 × 100%`（BR101：120 t ⇒ 102.2 kN；R+E 168 t ⇒ 138.4 kN） |
| 闸片摩擦 | `μ_b(v) = 0.39 − 0.00045·v_kmh`（下限 0.28）⇒ 100 km/h 0.345、200 km/h **0.30**（模块一给的低速 0.38–0.40 / 高速 0.30–0.32） |
| 电制动 | 三段式：低速淡出（`rheostaticFadeKmh`）→ 150 kN → **恒功率 `min(B_max, P_regen/v)`**；BR101 折点 **153.6 km/h**（6.4 MW），200 km/h 只剩 115 kN |
| 电空混合 | **电优先、机械补缺、EP 阀只削不加**（`blendingEnabled`，默认开）；司机电阻制动手柄与自动电制动**取大不相加** ⇒ 总力 = 司机诉求、缸压随速度被削 |
| 黏着截断 | 制动力合计 ≤ `μ_brake(v)·m·g`，`μ_brake(v) = min(7.5/(v_kmh+44)+0.161, 轨面 μ)`；**WSP 默认恒开**（钳到上限），关掉则断崖到 `wheelSlipMu`（0.12）。新标定下干轨/湿轨吃不穿，落叶/油污才截 |
| 宏观兜底 | UIC 制动重率法用于**未配气压链的车**与对账（它比铭牌口径保守约 30%，故不作标定源） |

**仍未做**：曲线阻力、隧道附加阻力、轴重转移、轮对角速度/滑移率（`μ–s` 与 WSP 的动态部分）、
车钩多体（自由间隙/缓冲器刚度/迟滞阻尼）、列车管**传播速度**（现在是单车等效管压，逐车传播待做）。

## 6. 车钩与编组纵向冲动（Coupler Dynamics）

长编组不能只用一个质点（否则没有断钩、挤压脱轨、"撞钩"质感）：

| 指标 | 含义与典型参数 |
| --- | --- |
| 车钩自由间隙 Slack | 钩舌间非受力死区，每副钩约 `15…30 mm`；整列累积可达数米 → 起步逐节碰撞的"冲动波" |
| 缓冲器刚度 `k` | 多段非线性（初段软、尾段极硬防撞底） |
| 迟滞耗能阻尼 `c` | 压缩/复原行程有摩擦迟滞圈，吸能 `60%…70%` |

## 7. 物理引擎积分与数值稳定性

- 轮轨微蠕滑刚度极大 ⇒ **刚性方程（Stiff ODE）**；
- 显式欧拉积分时物理 tick **≥ 200 Hz**（`Δt ≤ 5 ms`）；
- 或在车轮角速度求解上用**半隐式欧拉 / 隐式阻尼**，防止静止状态的数值震荡。
