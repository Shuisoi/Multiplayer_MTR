# MMTR 车辆打包 —— 用户必填输入清单（打包前你需明确提供的内容）

> 原则：**你逐项确认后再打包**。缺省项我会用括号里的默认值，但涉及几何/门/贴图语义的项请务必明确，否则结果不可复现。

## A. 车辆身份
| # | 必填 | 内容 | 示例 | 约束 |
| --- | --- | --- | --- | --- |
| A1 | 是 | 车辆 ID | `hst` | 小写 a-z0-9-_，资源命名空间/文件名用 |
| A2 | 是 | 显示名 | `HST (Create Export)` | 自由文本 |
| A3 | 是 | 列表颜色 | `7FA8CC` | 6 位十六进制 |
| A4 | 否 | 交通模式 | `TRAIN` | TRAIN/BOAT/CABLE_CAR/AIRPLANE |

## B. 车辆物理参数
| # | 必填 | 内容 | 示例 | 说明 |
| --- | --- | --- | --- | --- |
| B1 | 是 | 车长（格） | `15` | OBJ 模型长度方向的格数 |
| B2 | 是 | 车宽（格） | `5` | 模型宽度方向的格数 |
| B3 | 是 | 转向架数量 | `2` | 目前支持 2（两侧对称） |
| B4 | 是 | 转向架1位置 | `-5` | 距车中心沿车长方向偏移（格）；正=朝车头？由你按模型给符号 |
| B5 | 是 | 转向架2位置 | `5` | 同上 |
| B6 | 否 | 连挂余量1/2 | `0`/`0` | 车端空隙（格） |

## C. 模型与几何
| # | 必填 | 内容 | 示例/说明 |
| --- | --- | --- | --- |
| C1 | 是 | 源 OBJ 绝对路径 | `C:/…/hst_car.obj` |
| C2 | 是 | 贴图目录(含 MTL/PNG) | 通常与 OBJ 同目录 |
| C3 | 是 | 分组名映射(角色) | 见下 D 表——把 OBJ 里的 `o`/`g` 名逐条对应到角色 |
| C4 | 否 | 是否已按规范排轴 | 规范：X右/Y上/Z+朝车尾。若不知道给 rotationDegY 经验值 |
| C5 | 否 | 绕 Y 旋转角度 | 游戏导出版本经验 `-90`（车长由 X 转到 Z 轴） |
| C6 | 否 | 是否 X/Z 居中 | 默认 true（以整节车中心为原点） |
| C7 | 否 | 贴图V翻转 | flipTextureV 默认 true；颠倒则 false |

## D. 分组(部件)映射 —— 必填，逐条给
把 OBJ 里每个部件的**实际名字**告诉我对应哪个角色：
```
body     <- （实际组名，如 chunks_merged）
interior <- （实际组名，如 BlockEntities/material_0000；没有则填无）
door_l   <- 每扇左/前侧门组名（多门给 .001/.002… 列表）
door_r   <- 每扇右/后侧门组名
其他可动件/想单独分层的件：组名 → 角色名
```
> 未列出的组=当作车身合并/或告知我要跳过；会告警提示你核对。

## E. 门与透明
| # | 必填 | 内容 | 默认/说明 |
| --- | --- | --- | --- |
| E1 | 是 | 门动画类型 | STANDARD（常用）/ PLUG_FAST / BOUNCY… 不确定选 STANDARD |
| E2 | 是 | 开门滑动方向与幅度 | 沿车长方向；给正负+数值（像素，16px=1格；内置车 14）。例：左+14/右-14；不确定→先默认再游戏内反馈 |
| E3 | 否 | 需要 DOORWAY 门洞判定 | 默认自动生成（用门叶包围盒）；若你模型自带门洞组可告诉组名 |
| E4 | 否 | 透明件清单 | 哪些组/材质是玻璃要 INTERIOR_TRANSLUCENT；外壁玻璃需独立组 |
| E5 | 否 | 特殊部件 | 车头灯/亮灯件 → ALWAYS_ON_LIGHT/LIGHT 组；门灯 DOORS_OPENED/CLOSED 条件等 |

## F. 输出
