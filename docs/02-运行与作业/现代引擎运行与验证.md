# 08 让游戏跑在现代引擎（goal-A 使用与验证）

## 现状（2026-09）
- game 已能**编译并链接现代 MMTR 引擎**（含 mmtr 控制器与兼容层）；Java 21。
- 现代引擎能力：Vehicle 手动路径接入 DriveController；Simulator 自动加载车底配置；DEFAULT 保留旧行为。
- game 侧适配清单见 notes/05（已完成项）；遗留：未做 runClient 冒烟、外部进程桥（后续项）。

## 如何让默认车底走 MMTR 控制器（NOTCHED 等）
1. 准备一份车底配置：把 `mmtr/config-example/consist-types.json` 复制为
   `<世界数据>/mtr/<dimension>/mmtr-consist-types.json`。
   路径说明（dev/嵌入式）：engine rootPath = `<存档>/mtr`，dimension 子目录名见日志
   （常见 "minecraft/overworld" 对应子目录 minecraft/overworld）。
   找不到时：先 runClient 建一次世界后退出，再按上述路径放置文件。
2. 重启/重进世界，引擎日志会出现：
   `MMTR consist-type policy loaded for <dimension> (default=<id>)`
3. 未放置该文件 => 完全不启用，行为与 MTR 原版一致（安全兜底）。

## 驾驶验证（手动）
- 造车后上车手动驾驶（原 MTR 手柄语义仍可用）：动力档位与制动档位会经 legacy→ControlState 映射，
  由该车底 ConsistType 的控制器（NOTCHED/STEPLESS/AIR_BRAKE）决定实际牵引/制动。
- DEFAULT 模式车底 = 原引擎线性加减速，行为不变。
- 后续（键盘/HID 双路线 + 档位细分 UI）依赖 engine 正式接入后按 docs/07 接线。
