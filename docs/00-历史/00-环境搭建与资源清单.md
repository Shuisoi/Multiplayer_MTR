## 3. 运行前置（mods 目录用法）

- **Fabric 路线**：Fabric Loader + `mods/` 放入 `MTR-fabric-4.0.5+1.20.4.jar` 与 `fabric-api-0.97.3+1.20.4.jar`。MTR 的 fabric.mod.json 只声明依赖 `fabric` loader 与 `minecraft 1.20.4`，但 Modrinth 官方元数据把 Fabric API 标为 required，两者都放最稳。
- **Forge 路线**：MTR Forge 4.0.5 需 **Forge for 1.20.4（49.x）**。`tools/` 里的 `forge-1.20.1-47.4.23-installer.jar` 是 1.20.1 旧文件，**不适用 1.20.4**；若走 Forge 请另行安装 1.20.4 的 Forge 49.x（NeoForge 暂不受 MTR 4.0.5 支持）。
- Java：构建/开发 MTR 需 JDK 17（已备：`tools/jdk-17.0.20.1+1`）。系统 PATH 里的 Oracle Java 8 不要用于 MC 1.20.4。

## 4. Blockbench 安装与使用

- 安装形式：官方 Windows 便携版单 exe（无需管理员、无注册表），放在 `tools/Blockbench/`。
- 已验证：启动成功（主进程 + 多进程 Electron），并自动在 `%APPDATA%\Blockbench\` 生成配置，其中 **插件目录 `%APPDATA%\Blockbench\plugins\` 已创建**。
- 启动方式：双击 `tools/Blockbench/Blockbench_5.1.6_portable.exe`，或 `tools/Blockbench/启动Blockbench.bat`。
- 建模注意（MTR 官方 wiki）：
  - 新建模型必须选 **Modded Entity**，否则 MTR 无法读取；
  - 文件/分组/贴图命名仅允许小写 a-z、0-9、`_`、`-`、`/`；
  - 比例：1 游戏格 = 16 单位；车体通常离地 16 单位，宽 40–44 单位，一节车窗约 48 单位、车门约 32 单位（对平台门）；
  - 每个分组至少一个方块，方块缩放须为整数（小数用 inflate 实现）；
  - 导出的 .bbmodel 放在资源包 `assets/<ns>/models/...` 下，由 `mtr_custom_resources.json` 以 `<ns>:<path>` 引用。

## 5. “MTR Model Creator 插件”结论（重要）

多方核实（Blockbench 官方插件市场 `blockbench-plugins/plugins.json`、GitHub 仓库/用户/组织搜索、GitHub API、MTR 官方 wiki、grep.app 等）后：

1. **`MTR Model Creator` 是 MTR 3.x 时代的社区 Blockbench 插件**（作者社区昵称 Aso/asou），用于生成 MTR3 旧版车辆 JSON；它不是 MTR 官方仓库产物。
2. 到 2026 年：作者仓库不可访问、GitHub 上无有效官方分发（releases/仓库均查无）、也不在 Blockbench 官方插件列表中 → **不存在可验证的官方下载源**；从第三方镜像安装无法保证安全/兼容，故未安装任何来历不明的 .js。
3. MTR 4.0.5 的官方建模/发布流程**不需要任何 Blockbench 插件**：Blockbench 建模 → 资源包 `mtr_custom_resources.json`（新格式，schema 见 `docs/reference/`）→ 游戏内 **Resource Pack Creator**（网页 `http://localhost:<port>/creator/`）辅助生成与热重载；MTR3 旧格式仍可被自动转换（源码 `org/mtr/legacy/resource/CustomResourcesConverter.java`）。
4. 如果你仍想试用旧版社区插件：把社区提供的 `*.js` 放进 `%APPDATA%\Blockbench\plugins\` 并在 Blockbench 中启用即可（插件目录已建好）；或直接改用上面的官方流程。

## 6. 已落盘的参考资料（docs/reference/）

- MTR4 新格式 schema：`customResources / vehicleResource / vehicleModel / modelProperties / modelPropertiesPart / blockbenchModel / blockbenchElement / blockbenchOutline / blockbenchResolution / positionDefinition(s) / modelMirror / partPosition / resourceWrapper / objectResource / railResource / signResource / liftResource / minecraftModelResource` 等 `*.json`；
- MTR3 旧格式（自动迁移用）：`legacy_vehicleResource.json / legacy_railResource.json / legacy_signResource.json / legacy_objectResource.json`；
- 官方示例资源包：`MTR-Custom-Resources-example.zip`（结构见源码分析文档）。
